# 《我是造物主》音频方案 v1

> 专业域：音频设计 / 声音规格｜版本：v1（2026-10-26）｜作者：雷鸣远（音效总监）
> 前提：D4 已定 —— **不允许任何音频文件**。BGM / SFX 全部 WebAudio 程序合成；语音用 `speechSynthesis`。
> 依据：`docs/levels.md`（3 章 9 关 / 24 能力 / 台词）、`docs/research.md` 第四节、`docs/decisions.md` D4 / D5 / D6。
> 数值写法：一切绝对音量、毫秒、赫兹、循环周期 → `[待实机标定]`。本文只写**相对关系**与**结构**，不写死绝对值。

## 一、三层结构总表

| 层 | 唯一职责 | 承载的信息 | 触发者 | 持续 / 一次性 | 用户可否单独关 | 体积 |
|---|---|---|---|---|---|---|
| **BGM** | 告诉玩家「现在在哪一章、什么心情」 | 章节身份、情绪基线、压力有无 | 关卡状态机（章节进入 / 沙漏起漏 / 结算） | 持续，无 loop 点，实时生成 | 可 | 0 KB |
| **SFX** | 告诉玩家「这一下有多重、成没成」 | 因果反馈、物理重量、机关状态、UI 确认 | 每个游戏事件 | 一次性 | 可 | 0 KB |
| **语音** | 只负责「情绪高点的人格化」——好笑、被夸、被盖章 | 幽默、奖励、里程碑 | 白名单事件 + 冷却闸门 | 一次性，全局限量 | **可**（独立于 BGM/SFX） | 0 KB（系统音库） |

### 职责边界（不许越界）

| 禁止 | 原因 |
|---|---|
| **台词不做教程朗读** | 操作说明一律纯文字。成人被念三次就关声音（research.md D4 已判定）。 |
| **SFX 不做情绪评价** | 音效只说「发生了什么」，不说「你做得真好」。赞美是语音的独占职责。 |
| **BGM 不随每次操作变** | 逐笔响应会变成噪音墙。BGM 只认章节与压力状态，**不认单次成败**。 |
| **语音不做倒计时播报** | 「还有 10 秒」会制造焦虑且打扰 6 岁。时间压力只由 SFX 嘀嗒层与画面承载。 |
| **不用语音朗读屏幕上已有的长文本** | 大字台词 ≤18 字已由白名单控制；吐槽小字永不朗读。 |
| **不做音效闭环笑点** | 不出现「音效本身是笑话」的设计（如屁声、滑稽下滑音）。全年龄，且会廉价化。 |
| **SFX 不追求写实** | 纸感画风 + 写实音 = 违和。全部做「乐器化」的抽象音，不采样不拟真。 |

## 二、BGM 规格

### 2.1 总原则

| 项 | 规定 |
|---|---|
| 生成方式 | **实时音符调度**（lookahead scheduler），**不使用 AudioBufferSource 循环播放**。无 loop 点 = 天然无「8 秒腻」。 |
| 音阶 | 五声音阶（宫商角徵羽），**无半音、无导音** → 6 岁听着「不刺耳」，成人听着「不幼稚」 |
| 声部 | 三层：① 垫音垫（pad，长音铺底）② 低音根音（bass，段落锚点）③ 动机声部（motif，唯一有旋律感的层） |
| 和声写法 | 只给**根音 + 五度**（省三音）→ 空、留白、不像流行歌，不像游戏 BGM |
| 拍速范围 | ♩= 60–96 `[待实机标定]`；「慢慢来」开关开启时全章降档 `[待实机标定]` |
| 音色基底 | 三角波（温）+ 正弦（净）+ 极少量方波（硬边，仅第 2 章）；全部经一个低通 BiquadFilter |
| 噪声层 | 预生成 **1 秒白噪 buffer 复用**（不每次 new），经带通 → 「纸/风/翻页」环境层 |
| 响度 | BGM 总线恒定，**不做随关卡变化的整体音量抬升**（压力靠密度与音区，不靠音量） |

### 2.2 三章音乐性格差异（差异落在哪个参数上）

| 参数 | 第 1 章 · 造物实习期 | 第 2 章 · 造物投诉科 | 第 3 章 · 造物审计 |
|---|---|---|---|
| **调式** | D 宫（D E F♯ A B） | A 羽 ↔ C 宫 **交替**（羽宫互换 = 「不对劲」的笑点，不制造恐惧） | D 羽（D F G A C），四度偏低 → 明暗摇摆 |
| **和声推进** | D → Bm → G → A，四小节一轮，**每次都解决** | ii–V 反复，**故意不解决**（挂住） | 低音持续音 + 五度堆叠，无功能进行、无解决 |
| **拍速** | ♩= 60–66 `[待实]` | ♩= 76–84 `[待实]` | ♩= 88–96 `[待实]`（慢慢来：72） |
| **节奏密度**（每小节发音数） | 1–3 个，大量休止（留白 > 声音） | 1 个脉冲 + 每 2 小节一个切分 16 分短簇 | 每拍 1 个低音脉冲（稳定）+ 稀疏高音点 |
| **动机** | 4 音动机 A（上行 2 度 + 跳进），**完整** | 动机 A 的**倒影**（升→降），语序变错乱 | 动机 A **砍掉最后一个音**（3 音，悬着不落地） |
| **音色重心** | 三角波 + 慢低通 `[待实]` Hz，极柔 | 窄脉宽方波（文具/打字感）+ 玻璃感正弦泛音 + 低音 drone | 正弦 sub（体感）+ FM 短衰减木琴音（敲审计印章感） |
| **噪声层** | 纸页微风（低通噪声，几乎听不出） | 办公室底噪 + 极轻的「翻页」点缀 | 翻页 + 低频「滴答」层（仅在沙漏运转时存在） |
| **旋律自由度** | 高（动机音可跳音区） | 中（动机音必须回到主音附近） | 低（动机音级进，不许跳） |
| **情绪基线** | 好奇 · 有点呆 · 温暖 | 官僚 · 滑稽 · 憋着一口气 | 克制 · 有秤砣 · 但底下藏着温柔 |
| **一句话证据** | 「一张安静的纸」 | 「一台坏了的饮水机」 | 「一支正在称重的笔」 |

**章节切换点**：盖章音效 → 0.3 s `[待实]` 静默（换场呼吸）→ 新章 BGM 从**第 1 小节**淡入 `[待实]` ms，旧章以等功率交叉淡化退出。禁止硬切。

### 2.3 反重复策略（针对「8 秒循环就听腻」的 8 条具体手段）

| # | 手段 | 落地做法 |
|---|---|---|
| 1 | **根本没有循环素材** | 没有 loop 段。调度器每小节点生成音符，永不重复同一段音频。 |
| 2 | **动机变形而非动机重播** | 动机 A 有 4 个变形集：原形 / 倒影 / 缩短 / 加花。每个 2 小节随机取一个（加权，非均匀）。 |
| 3 | **洗牌袋选句法** | 4 个和声进行做成 bag，洗牌后依次取，**同一条连续不出现**（避免「又是这句」）。 |
| 4 | **休止符优先** | 每小节至少有 1 个八分休止。安静比音符更抗疲劳。 |
| 5 | **人味微扰** | 每个音符 onset ±`[待实]` ms、音高 ±`[待实]` cent、音量 ±`[待实]` dB 随机。人耳对「完全对齐」最敏感。 |
| 6 | **分层呼吸（16 小节级）** | 一个长周期层管理器：噪声层每 16 小节进/出一次；pad 的滤波截止频率做 30 s 级慢扫。玩家感觉不到「循环」，只感觉「空气在变」。 |
| 7 | **事件应答（call & response）** | 第 1 章：每次造物成型，BGM 立刻回一个高八度应答音（像世界在回应你）。这是**非周期**变化，主角每次画界面都不一样。 |
| 8 | **总时长兜底** | 单章连续停留 > `[待实]` 分钟（玩家卡关），BGM 自动**再降一层密度**（去掉动机层，只留垫音 + 低音）——声音变稀，暗示「没人催你」，不靠重复维持存在。 |

## 三、SFX 事件清单

> **音量基准定义**：以「盖章」为 0 dB 参考点（全场最响、唯一有仪式感的音），其余以相对偏移表示。所有绝对偏移 `[待实机标定]`。
> 合成通用件：`noiseBuf`（1 s 白噪，复用）+ `OscillatorNode` + `GainNode`(ADSR) + `BiquadFilterNode`。

### 3.1 核心事件表（必做）

| 事件 | 触发时机 | 合成方式（振荡器 / 噪声 / 滤波 / 包络） | 时长 | 音量基准 |
|---|---|---|---|---|
| `sfx_pendown` 落笔 | `pointerdown` 且首次进入绘制（非每次移动） | 白噪 → bandpass `[待实]` Hz（摩擦感）+ 一路低频正弦 `[待实]` Hz 极短（「落纸」的实体感）；attack 极快、decay `[待实]` ms | ~`[待实]` ms | −10 dB |
| `sfx_penup` 抬笔 | `pointerup` | 同落笔但更短、更高频段、更轻；decay 更陡（避免和落笔混淆） | ~`[待实]` ms | −16 dB |
| `sfx_penmove` 笔迹摩擦 | 绘制中限流触发（每 `[待实]` ms 最多 1 次，音量随速度微调） | 噪声 → bandpass，中心频率随笔画速度轻微上抬；非常轻，仅填手感 | 连续 | −24 dB |
| `sfx_spawn` 造物成型 | 笔画转刚体落地瞬间 | 双振荡（sine + triangle）音高上滑 `[待实]` → `[待实]` Hz，短衰减 + 一路纸响噪声尾 | ~`[待实]` ms | −6 dB |

| `sfx_combo` 能力组合触发（**奖励音**） | 两个能力首次叠加且判定成立 | 纯四度 + 纯五度叠置的上行三音 + 高频 shimmer（4 个正弦泛音、随机相位、快衰减）。**全场唯一的高亮度音色，稀缺性 = 奖励感** | ~`[待实]` ms | −2 dB |

| `sfx_ui` UI 确认 | 能力芯片选中 / 开关切换 | 单正弦 `[待实]` Hz，极短三角包络 | ~`[待实]` ms | −18 dB |
| `sfx_bubble` 文字气泡弹出 | 语音降级为气泡 / 吐槽字幕出现 | 极短纸沙沙（噪声 → 高通，decay 陡） | ~`[待实]` ms | −14 dB |
| `sfx_hint` 提示阶梯升级 | 第 2 次失败高亮 / 第 3 次失败画轮廓 | 柔和 ping（正弦 `[待实]` Hz，长衰减 `[待实]` ms），音量刻意低（提示不该抢戏） | ~`[待实]` ms | −16 dB |

### 3.3 能力音色：不给 24 个能力各做一个音

| 音色家族 | 覆盖能力 | 音色特征 |
|---|---|---|
| 硬 | 变硬 / 变重 / 无限长 | 低频 + 强分音 + 极短衰减（「实心」） |
| 轻 | 变轻 / 反重力 / 时间慢 | 高频上滑 + 气声噪声（「飘」） |
| 滑 | 会滚 / 滑 / 黏 | 低频颤音或滑音（「流动」） |
| 声 / 光 | 会说话 / 发光 / 透明 | 正弦泛音群 + 长衰减（「无形」） |
| 热 / 吸 | 可燃 / 吸水 / 导电 / 磁 | 噪声爆裂 + 断奏 tick（「活性」） |

规则：**家族决定音色，根音从该调式的 3 个音里随机取变体**。玩家听不出「24 个声音在打架」，但能听出「这一类能力感觉是一家人」。这也让 6 天工期可控。

### 4.3 台词表（24 条，全部 ≤18 字）

> 优先级：**P0** = 剧情骨架，不可被顶替 / 不可跳过；**P1** = 里程碑，可跳过；**P2** = 奖励赞美，可跳过且可丢；**P3** = 环境吐槽，可丢。

| # | 时机 | 说话人 | 台词（≤18 字） | 优先级 | 可跳过 |
|---|---|---|---|---|---|

| 2 | 3–8 s 造物簿出现 | 造物局广播 | 「他过不去。画点什么。」 | P0 | 否 |

### 4.6 降级策略（每一条都必须能在无中文语音的机器上跑通）

| 场景 | 处置 |
|---|---|
| `getVoices()` 首次返回空数组 | Chrome 异步填充：监听 `voiceschanged`，超时 `[待实]` ms（建议 1500）后判定不可用 → 切换 `audioMode = 'bubble'` |
| 有声音但**无 `zh-*`** | 判定不可用 → `bubble` 模式。**不用英文声音念中文**（会变成怪声，6 岁完全听不懂，比静音更糟） |
| `bubble` 模式行为 | 台词原样转手绘气泡（纸质感边框），停留 `[待实]` ms（建议 2500）；配 `sfx_bubble` + 该时机的情绪音（成功音 / 盖章音 / 组合音）。**语义零损失** |
| 无 `speechSynthesis` 对象（老浏览器） | 同 `bubble` 模式，不抛错、不 try/catch 静默吞异常（需 console 留一条 warn） |
| iOS / Chrome 需手势解锁 | 统一 `unlockAudio()`：首次 `pointerdown` 内一次性完成 `ctx.resume()` + `speak(空 utterance, volume=0)`；打 `unlocked = true` 标志，之后不再重复 |
| 解锁前触发语音 | 不丢事件：压入 `pendingQueue`（最多 1 条），解锁后 `[待实]` ms 内补播；超出 1 条则丢弃旧的 |
| Safari 切后台回来语音不出声 | `visibilitychange` → `resume` + `speechSynthesis.resume()` |
| 语音排队规则 | 单队列，**最多 1 条在播 + 1 条待播**。新语音优先级更高 → `cancel()` 后立即播；同级 → **丢弃新的**（绝不堆积，堆积 = 唠叨）。P0 永不被 `cancel` |
| `cancel()` 副作用 | `speechSynthesis.cancel()` 会清空**全部**队列，重播前必须重新 `enqueue` |
| 用户关掉语音 | 语音静音，**语义转气泡文字**（不静默消失）。`settings.voice=false` 存 `localStorage` |
| 用户全静音 | BGM + SFX + 语音全停；所有声音承载的信息（成功/失败/盖章/提示）必须有画面替代，不得造成信息缺失 |
| 语音中途被打断（切关） | 立即 `cancel()`，记 `lastLineId` 防止连播拦截误判 |

### 4.7 可配置项

| 项 | 默认 | 存 `localStorage` | 说明 |
|---|---|---|---|
| 主开关（总音量） | 开 | 是 | 三态图标：全开 / 仅音效（关语音）/ 全静音 |
| 语音开关 | **开** | 是 | 成人最常见的操作是「关语音」，必须独立可关 |
| BGM 音量 | `[待实]`（建议 0.35） | 是 | 不做细化滑杆，只做 低/中/高 三档 |
| SFX 音量 | `[待实]`（建议 0.7） | 是 | 同上 |

## 五、触发策略与工程约束

### 5.1 音频图（主链）

```
osc / noiseBuf ──> gainEnv(ADSR) ──> biquad ──┐
                                              ├─> busBGM   ─┐
                                              ├─> busSFX   ─┼─> masterGain ─> DynamicsCompressor ─> destination
                                              └─> busVOICE ─┘
speechSynthesis (独立于 WebAudio) ──duck 触发──> busBGM.setTargetAtTime()
```

| 节点 | 规定 |
|---|---|
| master 峰值 | ≤ −1 dBFS `[待实]` |
| 长时间平均响度 | `[待实]` LUFS（目标：手机小喇叭能听清 BGM 但不糊 SFX） |
| Compressor | threshold / ratio / attack / release 全 `[待实]`；作用：防多音叠加削波（单文件交付最容易翻车的地方） |
| 并发上限 | 同时发声节点 ≤ `[待实]`（建议 12）；超限时**丢弃音量最低的 SFX**，绝不丢弃 BGM 与语音 |
| 同 id 最短重触发 | `[待实]` ms（建议 30）；碰撞音额外**每帧 1 个**限流 |
| 调度方式 | lookahead scheduler：`setInterval` 25 ms / lookahead 120 ms `[待实]`；**禁止直接用 setTimeout 排音符**（抖动 = 节奏散） |
| 后台处理 | `visibilitychange` → `ctx.suspend()`；恢复 → `resume()` 并从**当前小节**继续，不从头 |
| 采样率 | 跟随 `AudioContext` 默认（通常 48 kHz），不强制转换 |
| 代码体积目标 | 音频模块 ≤ `[待实]` KB（未压缩建议 25 KB），**零外部请求** |
| 依赖决策 | **不引入 Tone.js**。裸 WebAudio 手写：三层 BGM 调度 + 24 个 SFX 约 `[待实]` 行即可覆盖。理由：单文件交付 + 体积 + 6 天工期，Tone.js 的抽象层反而增加调试面。此条交主程序复核 |

### 5.2 Ducking（说话时压音乐）

| 参数 | 值 |
|---|---|
| 触发 | `utterance.onstart` → true；`utterance.onend` / `onerror` / `cancel` → false |
| BGM 压低量 | `[待实]` dB（建议 −9 ~ −12） |
| SFX 压低量 | `[待实]` dB（建议 −3，几乎不压；音效是玩法信息，不能消失） |
| 起音 / 释放 | `setTargetAtTime`：起音 `[待实]` ms（建议 60）、释放 `[待实]` ms（建议 250）。**禁止直接赋值 gain**（会爆音） |
| 气泡模式 | 同样 ducking（气泡也是「有人在说话」），但压低量减半 `[待实]` |
| 兜底 | 若 `onend` 未触发（部分浏览器 bug），设 `duration` 上限超时 `[待实]` ms 后强制恢复 |

### 5.3 语速 / 音高（一人一格，用参数区分角色，不给每个角色找不同系统音）

| 说话人 | rate `[待实]` | pitch `[待实]` | volume `[待实]` | 备注 |
|---|---|---|---|---|
| 造物局广播 | 1.0 | 1.0 | 0.9 | 中性、机构腔 |
| 农夫 | 0.95 | 0.9 | 0.9 | 略慢、略低，老实人 |
| 南瓜 | 1.05 | 1.5 | 0.85 | 快、高（但**不能变成卡通鸭嗓**，全年龄下限） |
| 水泵 | 0.85 | 0.7 | 0.9 | 慢、低，工龄感 |
| 鼹鼠评论员 | 1.15 | 1.35 | 0.8 | 快嘴解说 |
| 守卫 | 0.9 | 0.85 | 0.9 | 装睡的中低音 |
| 桥 | 0.95 | 1.1 | 0.85 | 商人腔 |

| 闸 | 上限 |
|---|---|
| 单句时长 | ≤ `[待实]` ms（建议 4000）；超长台词**只走文字**（已由 ≤18 字约束覆盖） |
| 单关条数 | `[待实]`（建议普通 2 / 剧情 3） |
| 单局条数 | `[待实]`（建议 16） |
| **单局累计发声时长** | **`[待实]` ms（建议 ≤ 40 000，即 40 秒）** —— 通关 20–24 分钟的局，语音占比 < 3% |
| 单局 P2 赞美条数 | `[待实]`（建议 ≤ 8，即赞美库基本轮完一遍就到顶） |
| 超闸行为 | 到达上限后**全部语音静音**（只留气泡/字幕），直到新开一局。**不做「上限提示」**（提示本身也是唠叨） |

### 5.5 工期护栏（6 天，音频只能占小头）

| 优先级 | 内容 | 可砍性 |
|---|---|---|
| **P0 必做** | master/bus 三总线 + Compressor；6 个 SFX（落笔 / 造物成型 / 能力贴附 / 成功 / 失败 / 盖章）；BGM 第 1 章单层垫音；语音 8 条（开箱 2 + 首次成功 + 首次盖章 + 连败 2 + 章末 + 终局 2） | 不可砍 |

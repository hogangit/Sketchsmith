## 二、核心循环（6 行）

1. **看到困境**：一屏静态场景，一个角色卡在某个缺口前，用一句话说清「我为什么过不去」（≤20 字）。
2. **动笔画**：屏幕下半部是造物簿，玩家随便画——系统不猜你画的是什么，只量你的笔。
3. **读几何**：提取长度 / 闭合性 / 面积 / 重心 / 笔画数 → 变成梁、轮、团块、容器、绳或松散堆（映射见附录 A）。
4. **给能力**：从本关 5–6 个能力芯片里点 1–2 个（能力只改行为规则，不改形状）；可选输入「修饰词+名词」命名，名字只影响台词。
5. **放下 → 生效**：造物落入场景参与物理，角色自己会去用它；成功则进过关演出。
6. **失败也有内容**：造物不消失、进度不重置、无死亡，只换来一句新的吐槽台词 + 提示升级（第 2 次失败高亮可交互点，第 3 次失败直接演示轮廓）。

## 三、能力池 v1（24 个）

**池子规则**
- 全局 24 个，但**单关最多露出 6 个**（本关必需 2–3 个 + 3 个干扰项）。全局增长不等于单屏增长。
- 前 3 关累计只用 **4 个**能力（变硬 / 变轻 / 会滚 / 变重），防认知过载。
- 每个能力的规则都必须是可写成 if-then 的物理参数改写，禁止「变得更强」类描述。
- 「看着没用」标记 ⚠️ 的三个（怕痒 / 变轻 / 会说话）单独使用几乎无解，配对后能破关——这是本作的组合乐趣来源。

|---|---|---|---|---|---|

| 2 | 变轻 ⚠️ | 自身 | 质量 ×0.2，可被风场与上升气流推动（单独用几乎改变不了结局） | 第1章 | 是 |
| 3 | 会滚 | 自身 | 与地面摩擦系数降至 ≈0，接触斜坡时持续加速 | 第1章 | 是 |

**「看着没用，配对逆天」的三条组合（必须实装，它们是笑点与爽点的交汇处）**

| 组合 | 单独看 | 配起来 | 用在哪关 |
|---|---|---|---|
| 怕痒 + 变硬 | 一个被碰就乱弹的软东西 | 不变形的弹射板：小人踩上去、平台边缘一碰 → 弹射上高台 | 关4 |
| 会说话 + 透明 | 一个只会念台词的东西 | 只闻其声不见其物：把守卫全引走，自己空门入户 | 关5 / 关6 |
| 变轻 + 吸水 / 反重力 | 轻东西自己会飞走，很麻烦 | 变轻后能被上升气流托住 → 空中浮桥 / 气球吊舱 | 关2 / 关8 |

## 四、关卡表（9 关）

### 关1 · 一个洞 ｜ 难度 1

| 字段 | 内容 |
|---|---|
| 困境 | 农夫站在左边，右边是他种的田。中间一道沟，宽约三个身位，他跳不过去。他会走到沟边、探头、退回来、再走过去——**不用文字也看得懂他缺一座桥**。 |
| 可用能力池 | 变硬（首屏只露这一个）；第 2 次尝试时解锁「变轻」。共 2 个。 |
| 参考解法 | ① 横向画一条长笔画（长宽比 > 6:1 未闭合）→ 梁 → 变硬 → 架在沟上，农夫走过。<br>② 画一个小闭合圆 → 小颗粒/团块 → 变硬 → 垫脚石，农夫踩着沟壁凸起跳过去。<br>③ 画长条但不加能力 → 太软自己塌进沟里（教学性失败）。 |
| 自由造物槽在说什么 | 造物落地后农夫绕它转一圈，按几何属性说一句：梁 →「这东西能踩吗？」团块 →「你是不是想让我踩这个？」名字只出现在他心里默念的小字里。 |
| 失败会怎样 | 造物掉沟里**不会消失**，卡在沟底变成装饰。农夫坐沟边捶腿说一句吐槽。第 2 次失败时沟壁踏点发光（暗示解法②）；第 3 次失败直接在半空画出梁的轮廓虚线。 |
| 笑点落点 | 关名本身：他掉下去之后说「现在它是个更好的洞了」。以及他对形状的审美点评：「我不评价你的画，但它得能承重。」 |
| 难度 | 1 |

### 关2 · 滚下去的南瓜 ｜ 难度 2

| 字段 | 内容 |
|---|---|
| 困境 | 农夫要把一颗比自己大的南瓜运到山脚集市。他推不动，南瓜也不肯自己走（它是方的——设定上它是方的，肉眼可见）。前方是下坡。 |
| 可用能力池 | 变硬、变轻、会滚（3 个） |
| 参考解法 | ① 画闭合圆 → 轮 → 会滚 → 把南瓜架上去滚下山。<br>② 画长条 → 变硬 → 滑道，配合「变轻」把南瓜推上去滑下去。<br>③ 画大闭合团块 → 变轻 → 变成气球系在南瓜上，一起飘下山谷。 |
| 自由造物槽在说什么 | 南瓜点一下可以命名，它会用名字自我介绍，并质疑你的命名品味。农夫会补一句评价。 |
| 失败会怎样 | 南瓜滚错方向：撞翻集市摊子 / 滚进小河。舞台不重置，摊子留在原地当永久装饰。农夫看着河说「它现在是一条鱼了」。 |
| 笑点落点 | 给南瓜起名「我爸的遗产」；南瓜坚持自己是圆的、是这个世界把它磨方了。 |
| 难度 | 2 |

### 关3 · 踩不动的水泵 ｜ 难度 2

| 字段 | 内容 |
|---|---|
| 困境 | 田里干裂，要人踩水泵踏板才出水。农夫体重不够，跳上去也压不动。旁边有一根杠杆。 |
| 可用能力池 | 变硬、变轻、会滚、变重（4 个，至此第 1 章能力池封顶） |
| 参考解法 | ① 画团块 → 变重 → 压在踏板上持续出水。<br>② 画长条 → 变硬 → 杠杆，把变重的造物放在短端压下长端。<br>③ 画闭合圆 → 会滚 + 变重 → 滚石反复碾压踏板（成功率低但可行，属于老手解法）。 |
| 自由造物槽在说什么 | 水泵会说话（它有三十年工龄），它不看你的造物，只评价你的敬业程度。 |
| 失败会怎样 | 水压不足或泵被压坏：水柱喷农夫一脸。他擦脸说「至少我洗了个头」。泵咳两声继续可用，不修也不影响重试。 |
| 笑点落点 | 水泵的工龄抱怨；农夫被喷水后仍坚持验收。 |
| 难度 | 2 |

> 第 1 章结束盖章演出：「你已通过 · 能不能让东西听话」。

### 关4 · 上不去的高台 ｜ 难度 3

| 字段 | 内容 |
|---|---|
| 困境 | 小人要上一个比自己高四倍的平台，平台边缘有块薄石台（可以踩）。他自己跳不到，也没有梯子。 |
| 可用能力池 | 变硬、变轻、会滚、变重、怕痒、黏（6 个，含 2 个干扰项） |
| 参考解法 | ① 画长条 → 变硬 + **怕痒** → 不变形的弹射板：小人踩住一端，另一端被石台碰一下 → 把他弹上去。<br>② 画三个不相连的圈 → 松散堆 → **黏** → 三块焊成楼梯。<br>③ 长条 → 变硬 → 斜靠在平台边当斜坡（需要精准角度，老手解法）。 |
| 自由造物槽在说什么 | 造物被踩时“哎哟”一声；小人吐槽它「你能不能有点职业素养」。 |
| 失败会怎样 | 造物弹飞砸到小人，或小人摔进草丛。草丛里坐着一只**鼹鼠评论员**，鼓掌并打分（它会一直留在场景里，之后每关失败都可能出现）。 |
| 笑点落点 | 鼹鼠评论员首次登场：「摔倒动作我给 8 分，落地我给 3 分。」 |
| 难度 | 3 |

### 关5 · 会咬人的河 ｜ 难度 3

| 字段 | 内容 |
|---|---|
| 困境 | 河里有会咬东西的鱼，任何靠近的东西都会被咬。原本的桥被咬断了，对岸有个小人要过来。（鱼不咬人，只咬桥——这句设定要明说，防止儿童害怕。） |
| 可用能力池 | 会说话、透明、滑、黏、变硬、会滚（6 个） |
| 参考解法 | ① 画团块 → **会说话 + 透明** → 只闻其声不见其物，鱼全追着声音游到河湾，小人从浅滩过来。<br>② 长条 → 变硬 + **滑** → 桥面极滑，鱼跳上来直接滑回水里。<br>③ 长条 → 变硬 → 架桥，再「黏」住两岸（鱼咬不断焊死的接头）。 |
| 自由造物槽在说什么 | 造物会说的第一句话由名字生成；鱼会跟它对话（「你是一块会说话的石头吗」「我是桥」「那不咬了」）。 |
| 失败会怎样 | 桥被咬断，小人掉进河里被鱼顶着来回漂，但**不受伤**：他浮在水面说「我没事，只是尊严受损」，然后自己游回岸上，等你再画。 |
| 笑点落点 | 鱼的逻辑：「别跑，我只是想咬一口确认你是不是桥。」+ 小人对尊严的执着。 |
| 难度 | 3 |

### 关6 · 守门人 ｜ 难度 3（首个复合缺口）

| 字段 | 内容 |
|---|---|
| 困境 | 一扇门，门上有两个条件：**机关被足够重的东西压住** + **门口感光石要见光**。守卫坐在门口打瞌睡，不会帮你。玩家只有一个造物槽，必须一次满足两个条件。 |
| 可用能力池 | 变重、发光、会滚、会说话、可燃、透明（6 个） |
| 参考解法 | ① 画团块 → **变重 + 发光** → 一个又重又亮的东西压在门口（两个旧能力第一次同用 = 复合）。<br>② 闭合圆 → 发光 + 会滚 → 发光球滚到感光石前，光把守卫晃醒 → 他去搬石头压机关。<br>③ 会说话 → 造物在守卫耳边念台词，吵醒他（他醒来后自己会去开门，只要感光石亮着）。<br>④ 可燃 → 冒烟把守卫呛醒（惩罚性幽默解法）。 |
| 自由造物槽在说什么 | 守卫对造物的第一反应；造物的名字会被他写进门卫登记簿（「登记姓名：我爸的遗产。理由：来访。」）。 |
| 失败会怎样 | 门不开，天黑了，守卫说「明天再来吧」——然后时间瞬间天亮（他根本没睡够）。失败不重置，天亮后条件照旧。 |
| 笑点落点 | 守卫：「我没有在睡觉。我在闭眼巡逻。这是两个完全不同的工种。」 |
| 难度 | 3 |

> 第 2 章结束演出：造物投诉科给你寄来一张联名信，上面有 12 个歪歪扭扭的签名。

### 关7 · 收税的桥 ｜ 难度 4（首次时间压力）

| 字段 | 内容 |
|---|---|
| 困境 | 一座活着的桥要收过桥费，小人必须在沙漏漏完前把货送到对岸。桥故意垮掉一半，还在讨价还价。 |
| 可用能力池 | 无限长、复制、时间慢、黏、变硬、变轻（6 个） |
| 参考解法 | ① 长条 → 变硬 + **无限长** → 一次跨过整条河（无视垮掉的那一半）。<br>② 团块 → **复制 + 黏** → 一次造出三块自焊台阶，两步过河。<br>③ 长条 → **时间慢** → 慢动作里从容搭板（沙漏也变慢，因为时间慢作用于全场刚体；沙漏不算刚体，所以这是高难解法，需谨慎——`[待主程序实测标定]` 沙漏是否受时间慢影响）。 |
| 自由造物槽在说什么 | 桥会跟造物讨价还价、索要贿赂；造物可以用名字“支付”（名字只影响台词，不影响判定）。 |
| 失败会怎样 | 时间到，货被桥扣下当过桥费。小人不生气：「我用一车萝卜换了一句谢谢。」萝卜变成桥上的装饰，永久留着。 |
| 笑点落点 | 桥收「谢谢」当收据；收据上盖着宇宙公章。 |
| 难度 | 4 |

### 关8 · 断层 ｜ 难度 4（需要预判物理）

| 字段 | 内容 |
|---|---|
| 困境 | 地面裂开一道又宽又深的缝，缝底是岩浆（**不致命**，会把东西弹回来）。所有旧办法同时失效：普通长条不够长、团块直接掉下去、滚的会栽进缝里。 |
| 可用能力池 | 无限长、变重、磁、反重力、变硬、会滚（6 个） |
| 参考解法 | ① 长条 → **无限长 + 变重** → 两端压住缝两侧石台。<br>② 团块 → **磁** → 吸住缝底的铁块，被拉上去形成踏板链。<br>③ 长条 → **反重力** → 从缝底向上浮，自己浮成一座桥。<br>④ 闭合圆 → 会滚 + 变重 → 沉到缝底被弹回，反复弹起当跳板（极难，老手解法）。 |
| 自由造物槽在说什么 | 造物掉进岩浆会“尝”一口（它有味觉，这不科学），然后评价岩浆的味道。 |
| 失败会怎样 | 造物沉下去被弹回、糊在农夫脸上。他舔一下说「咸的」，然后继续等。岩浆不会吞掉任何东西，缝底始终可见（避免失败恐惧）。 |
| 笑点落点 | 岩浆是「宇宙的剩汤」；农夫对味道的执着。 |
| 难度 | 4 |

### 关9 · 审计员 ｜ 难度 5（终局 · 三阶段）

| 字段 | 内容 |
|---|---|
| 困境 | 宇宙审计员收走你全部造物，逐条检查「有没有偷工减料」。三个阶段：<br>**① 收名字**：禁止命名，只能画（揭示「名字只是外观」）。<br>**② 窄缺口 + 倒计时**：一个比你的造物还窄的缝，同时沙漏在漏。<br>**③ 命题造物**：他要求你造一个「能自己通过缺口的东西」——必须同时用到正确形状 + 两个能力。 |
| 可用能力池 | 每阶段从 6 个里**只能选 2 个**（限次是本关唯一的规则变化）：<br>① 变硬 / 变轻 / 会滚 / 滑 / 黏 / 透明<br>② 无限长 / 复制 / 时间慢 / 变重 / 磁 / 反重力<br>③ 怕痒 / 变硬 / 反重力 / 无限长 / 复制 / 黏 |
| 参考解法 | ① 阶段二：长条 + 无限长（一次跨过）；或 团块 + 复制（三块连跳）。<br>② 阶段三：长条 + **怕痒 + 变硬** → 自己弹过缺口；或 长条 + **反重力 + 无限长** → 自己浮过去；或 团块 + **复制 + 黏** → 自己搭桥后滚过去。<br>至少三条互不相同的路径，证明终局不是唯一答案。 |
| 自由造物槽在说什么 | 最后一句台词由「形状 + 能力」组合生成，是**造物自己**对审计员说的，不是玩家说的。玩家在此前每一关给它起的名字会在这句里被引用一次。 |
| 失败会怎样 | 审计员开罚单，罚单内容随失败原因变化（「第 3 条：桥不够长，却自称是桥」）。第 3 次失败他本人笑场，主动泄露一句答案（他对造物这件事的兴趣，就是结尾伏笔）。 |
| 笑点落点 | 审计员的公文腔：「根据《宇宙造物管理条例》第 0 条——所有东西必须有用。你造的这个……（翻页）……你自己解释一下。」最后揭穿他自己偷偷画了个歪歪扭扭的小人。 |
| 难度 | 5 |

## 五、难度曲线（每关新增的**认知变量**，不是「更难」）

| 关 | 新增认知负担（多出来的那一个变量） | 变量数 | 玩家需要的思维动作 |
|---|---|---|---|
| 1 | **零**：只学「画 → 落地 → 生效」一条因果链 | 1 | 相信笔 |
| 2 | **形状决定形态**：圆和长条放下去结果不同 | 2 | 选形状 |
| 3 | **能力改变规则**：同一形状 + 不同能力 = 不同结果 | 3 | 选能力 |
| 4 | **配对**：两个能力相乘，且其中一个单独用是废物 | 4 | 做加法 |
| 5 | **作用对象从我方转向环境/敌方**：能力不只用在自己身上 | 5 | 换个对象用 |
| 6 | **复合缺口**：两个条件必须由同一个造物同时满足 | 6 | 一次满足两件事 |
| 7 | **时间压力**：规划时间被压缩（沙漏只在对的时机开始漏） | 7 | 边想边做 |
| 8 | **深度预判**：缝太深，必须先想清后果才敢放手 | 8 | 先猜后做 |
| 9 | **约束下的组合**：限次 + 多阶段 + 不能命名（不能靠名字自我暗示） | 9 | 在限制里复用全部积累 |

> 每关**只加一个**变量，且旧变量全部保留（能力池不清空、自由造物槽不清空）。这是「从易到难」的唯一可执行定义。

## 六、全年龄适配（同一关如何同时服务 6 岁与 30 岁）

| 机制 | 对 6 岁的效果 | 对 30 岁的效果 |
|---|---|---|
| **三级提示阶梯**：失败 1 次→台词暗示；2 次→可交互点高亮；3 次→直接画轮廓虚线演示 | 卡住不超过 40 秒，不会哭 | 不失败就看不到提示，全程自己解，不会觉得被当小孩 |
| **每关 1 个隐藏解法**（不写进任何提示，见各关解法③④） | 不影响通关 | 结算给称号（如「用一句话说服鱼的人」），提供二次游玩价值 |
| **失败零成本**：造物不消失、进度不重置、无死亡、无倒计时（除关7/9） | 不怕做错，敢乱画 | 失败变成读台词的内容，不是惩罚 |
| **「慢慢来」开关（默认开启）**：关7 / 关9 的沙漏只在你动笔时走，停笔即暂停 | 完全消除时间焦虑 | 想要压力时在设置里关掉，变回硬计时 |
| **文案双层**：大字是白话（6 岁懂）+ 小字是吐槽（成人才笑） | 只看大字和动作 | 只为小字留下，记住审计员那句公文腔 |
| **命名不判错**：孩子写「阿巴阿巴」也照样生效，只影响台词 | 写什么都行，立刻有反馈 | 认真起名的人会得到更好的台词，形成自我奖励 |
| **绝不语言打击**：所有吐槽对象是**情境**和**角色**，不是玩家的画 | 不会因为画得丑被羞辱 | 审美自嘲变成共同笑点，不是嘲弄 |

**禁止项**：不做难度选择菜单（6 岁会乱点）；不做失败结算页（打断心流）；不做文字教程关（30 秒内必须能玩）。

## 七、叙事骨架（≤15 行）

1. 你是**宇宙造物局 307 号隔间（正在装修）的实习造物主**，工位在宇宙尽头，右边是一台坏了的饮水机。
2. 你能造物，因为你继承了一支**造物笔**——但它有个缺陷：**它只读形状，听不懂名字**。所以你造的东西经常不理你。
3. 第 1 章：实习期派你去一个农夫的世界补洞。农夫是你的第一个甲方，非常难搞，且对形状有强烈审美意见。
4. 第 2 章：你造的 12 个东西联名写信投诉你，投诉理由统一为「命名敷衍」。投诉科的窗口贴着「今日号已发完」。
5. 第 3 章：宇宙审计员来查你偷工减料，第一件事是**把你的命名权收走**——他要看没有名字的造物还成不成立。
6. 结尾：你造的东西替你自己说了话。审计员在你的罚单上写下「不合格」，但在签收栏里，他偷偷画了一个歪歪扭扭的小人。
7. 那个小人是他这辈子想造的第一个东西。他也想造物，只是没人给他笔。
8. 他把笔还给你，说：「现在你可以造没用的东西了。」→ **沙盒解锁**。

**5 条真实可用台词**

1. 农夫（关1，看到梁）：「这玩意儿能踩吗？我是说，我踩了它会不会觉得被冒犯。」
2. 南瓜（关2，被命名后）：「你管我叫『我爸的遗产』？我是一颗南瓜。」
3. 水泵（关3）：「我在这儿被踩了三十年。三十年。你猜上一个踩我的人现在在哪？（停顿）他还在踩。」
4. 守卫（关6，被吵醒）：「我没有在睡觉。我在闭眼巡逻。这是两个完全不同的工种。」
5. 审计员（关9）：「根据《宇宙造物管理条例》第 0 条——所有东西必须有用。你造的这个……（翻页）……你自己解释一下。」

## 八、首关开箱设计（30 秒生死线）

| 时间 | 屏幕上发生什么 |
|---|---|
| 0–3 s | 黑屏。一笔手绘线条自己画出一只眼睛，睁开；镜头拉远——是农夫的脸。他说：「你是谁？」（全屏唯一文字） |
| 3–8 s | 画面往下一沉，露出造物簿（手绘质感画布）。上面只有一行：「他过不去。画点什么。」**没有按钮、没有菜单、没有教程文字**。 |
| 8–15 s | 第一笔随便画，画布全盘接收、不判错、不设笔数上限。落笔瞬间有纸笔摩擦音。 |
| 15–22 s | 造物落地 → 头顶浮出一颗**灯泡**（首关只给「变硬」这一个能力，不弹面板）。点灯泡，造物变硬并有金属声。 |
| 22–28 s | 农夫走过去踩上、过沟。他回头说第一句感谢（其实是一句吐槽）。盖章音效：「实习期 · 第 1 件作品」。 |
| 28–30 s | 第 2 个能力「变轻」解锁（不解释，放在那里等玩家自己发现）。 |

**硬指标**：30 秒内必须发生「我画的东西真的动了，还被人用了」这一件事。全流程单屏文字 ≤ 25 字。手机竖屏优先，画布占下半屏 45%。

## 附录 A · 形状 → 形态映射（关卡可解性的前提，供主程序承接）

| 几何判定（全部阈值 `[待主程序实测标定]`） | 物理形态 | 行为基调 | 关卡里的用途 |
|---|---|---|---|
| 笔画数 ≥3 且互不连接 | 松散堆 | 多块小刚体，会散 | 台阶原料（需「黏」） |
| 笔画数 ≥2 且首尾相连 | 绳 | 柔性链，可缠绕、可悬挂 | 吊桥、套索 |
| 长宽比 > 6:1 且首尾未闭合 | 梁 | 长刚体，两端可支撑 | 桥、杠杆、滑道（最常用） |
| 首尾闭合 且 长宽比 ≤ 1.5 | 轮 | 圆柱刚体，可滚 | 轮子、滚石、球 |
| 首尾闭合 且 长宽比 1.5–3 | 团块 | 软刚体，可堆叠、可压 | 垫脚石、压舱、诱饵 |
| 首尾闭合 且 内部有孔 | 容器 | 中空，可装水/装物 | 舀水、装鱼 |
| 闭合 且 面积 < 小阈值 | 颗粒 | 质量极小 | 投掷物、诱饵 |
| 其余一切 | 团块（兜底） | — | 永不判错，只是不好用 |

> **设计铁律**：任何关卡的必需解法都必须存在**至少一个「团块（兜底形态）+ 某能力」**的可行路径。这样玩家画得再丑也不会走进死路——「画得丑」只能让他多花 30 秒，不能让他过不了关。

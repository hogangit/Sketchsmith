## 二、核心循环（6 行）

1. **看到困境**：一屏静态场景，一个角色卡在某个缺口前，用一句话说清「我为什么过不去」（≤20 字）。
2. **动笔画**：屏幕下半部是造物簿，玩家随便画——系统不猜你画的是什么，只量你的笔。
3. **读几何**：提取长度 / 闭合性 / 面积 / 重心 / 笔画数 → 变成梁、轮、团块、容器、绳或松散堆（映射见附录 A）。
4. **给能力**：**能力芯片随关卡解锁**——第 1 关造物簿上只有 1 格，逐关增加，第 6 关起封顶 6 个（见第三节解锁节奏表）；玩家从本关面板里点 1–2 个（能力只改行为规则，不改形状）；可选输入「修饰词+名词」命名，名字只影响台词。
5. **放下 → 生效**：造物落入场景参与物理，角色自己会去用它；成功则进过关演出。
6. **失败也有内容**：造物不消失、进度不重置、无死亡，只换来一句新的吐槽台词 + 提示升级（第 2 次失败高亮可交互点，第 3 次失败直接演示轮廓）。

> **R2 统一口径（核心循环侧）**：核心循环里的「能力芯片」不是固定 5–6 个——它是**随关卡逐关变多的一排格子**，第 1 关 1 个、第 6 关起封顶 6 个。任何文档、界面、宣发文案都不许再写「5–6 个能力芯片」。

## 三、能力池 v2（24 个）· 含芯片解锁节奏

**池子规则**
- **R2 统一口径（能力池侧）**：全局共 24 个能力，但**单关面板露出的芯片数 = 该关卡号（第 1 关 1 个 → 第 6 关起封顶 6 个）**。数量增长到此为止，之后只轮换内容、不再加密。
- 面板是「本关可用清单」，不是永久底栏：已解锁的能力按本关教学需要挑选进场，不必每关全带（关 4 起开始轮换）。
- 前 3 关累计只出现 **3 个**能力（变硬 / 会滚 / 变重），防认知过载。
- 每个能力的规则都必须是可写成 if-then 的物理参数改写，禁止「变得更强」类描述。
- 「看着没用」标记 ⚠️ 的三个（怕痒 / 变轻 / 会说话）单独使用几乎无解，配对后能破关——这是本作的组合乐趣来源。
- **音色家族（音频侧 v2，24 个能力穷举分 5 类，固定不动）**：硬 = 变硬·变重·无限长·防水｜轻 = 变轻·反重力·时间慢·倒转·会跳｜滑 = 会滚·滑·黏·吸水｜声/光 = 会说话·发光·透明·复制｜活性 = 可燃·导电·磁·怕痒·记仇·饿·一刀切。
  逐关核算结果：**没有任何一关需要为音色调整芯片**。关6（声光×3）与关8（硬×4）的家族扎堆是**主题同构**，换掉反而拆散主题；关1–3 覆盖只有 1–2 家，但前 3 关芯片数 = 必需数、没有干扰项可换，且第 1 章 BGM 音色统一，听感不单调。后续若加关或换芯片，优先在**干扰项**上避开「6 个芯片全落同一家族」，不动必需解法。

## 四、机关原型（R3）· 全作只用 4 类

**工期约束**：9 关不是 9 套机关。全部关卡用到的机关抽象为 **4 类原型**，每类只做一套程序实现 + 若干参数变体。

| 原型 | 判定规则（一句话，程序可实现） | 允许的参数变体（不算新原型） |
|---|---|---|
| **压板** | 承受 ≥W 的**持续**重量 → 状态翻转（开 / 关 / 持续输出），撤重即回弹 | 踏板 / 机关盘 / 配重桥面 / 需要持续压住的常开型 |
| **感光** | 光照半径覆盖判定点 → 状态翻转（开），光照撤除即回弹 | 感光石 / 暗区生物驱散 / 门上的第二个条件 |
| **咬合** | 接触即抓取或破坏：把接触物**固定住 / 移除 / 打断**三选一 | 咬人的鱼 / 活着的桥 / 藤蔓 / 守卫的登记簿（只固定不破坏） |
| **沙漏** | 只做计时与阶段切换，**不参与物理，不受「时间慢」影响** | 关内倒计时 / 阶段计时 / 停笔即暂停 |

**关卡 → 原型映射**

| 关卡 | 用了哪几类原型 | 组合方式 |
|---|---|---|
| 关1 一个洞 | **无** | 纯地形缺口。压力来自「不确定该画什么」，不需要机关 |
| 关2 滚不动的南瓜 | **无** | 纯地形落差（两岸等高、中间一道深沟）+ 一个可命名刚体（南瓜），不加机关 |
| 关3 踩不动的水泵 | **压板** | 单原型：压板（水泵踏板），唯一变量是「重量阈值」 |
| 关4 上不去的高台 | **无** | 纯地形高度差；那块薄石台是**地形**，不是机关 |
| 关5 会咬人的河 | **咬合** | 单原型：只取「破坏接触物」这一侧（咬断桥面） |
| 关6 守门人 | **压板 + 感光** | 双原型**并联（AND）**：同一个造物必须同时压住压板并照亮感光石——全作唯一的复合缺口关，也是本作机关复杂度的上限 |
| 关7 收税的桥 | **沙漏 + 咬合** | **串联（时序）**：咬合（活桥扣下货物）决定失败代价，沙漏（倒计时）决定节奏。「时间慢」只拖慢咬合方与刚体，拖不慢沙漏 |
| 关8 断层 | **无** | 纯物理：深度 + 岩浆的弹性反馈。第 3 章故意留一关完全不靠机关，只靠预判 |
| 关9 审计员 | **沙漏** | 只用一处（阶段二倒计时）。其余压力来自**规则限制**（禁命名 / 每阶段限选 2 个能力），不属机关 |

**结论与施工约束**
1. 9 关只用到 4 类原型；其中 4 关（1 / 2 / 4 / 8）**完全不用机关**；最高组合度是关6 的 2 类并联，没有 3 类叠加。
2. **没有第 5 类的需求**。若后续版本真要新增，只允许在四类上加参数（例如「压板阈值随次数递增」），不允许新增原型。
3. 池内的「导电 / 吸水 / 一刀切 / 饿」在本 9 关内**不承当必需路径**，因此**不新造电路、水位、切割、吞食类机关**；它们在关卡里只作干扰项。

### 关1 · 一个洞 ｜ 难度 1

| 字段 | 内容 |
|---|---|
| 困境 | 农夫站在左边，右边是他种的田。中间一道沟，宽约三个身位，他跳不过去。他会走到沟边、探头、退回来、再走过去——**不用文字也看得懂他缺一座桥**。 |
| 本关露出芯片 | **1 个**：变硬（造物簿上只有这一格，不弹面板） |
| 参考解法 | ① 横向画一条长笔画（长宽比 > 6:1 未闭合）→ 梁 → 变硬 → 架在沟上，农夫走过。<br>② 画一个小闭合圆 → 颗粒/团块 → 变硬 → 垫脚石，农夫踩着沟壁凸起跳过去。<br>③ 画长条但不加能力 → 太软自己塌进沟里（教学性失败）。 |
| 自由造物槽在说什么 | 造物落地后农夫绕它转一圈，按几何属性说一句：梁 →「这东西能踩吗？」团块 →「你是不是想让我踩这个？」名字只出现在他心里默念的小字里。 |
| 失败会怎样 | 造物掉沟里**不会消失**，卡在沟底变成装饰。农夫坐沟边捶腿说一句吐槽。第 2 次失败时沟壁踏点发光（暗示解法②）；第 3 次失败直接在半空画出梁的轮廓虚线——**并且这条虚线是用「一笔拉通、中途不停笔」的手动画出来的**（同一段动画，成本为零）。注意：这只演示一笔的画法，**不暗示「两笔是错的」**——两笔细长会判成带接痕的梁；两笔略胖会判成**团块**（兜底形态），加变硬后照样能踩。两条路都通。 |
| 笑点落点 | 关名本身：他掉下去之后说「现在它是个更好的洞了」。以及他对形状的审美点评：「我不评价你的画，但它得能承重。」 |
| 难度 | 1 |

### 关2 · 滚不动的南瓜 ｜ 难度 2

| 字段 | 内容 |

### 关7 · 收税的桥 ｜ 难度 4（首次时间压力 · R1 裁定已执行）

| 字段 | 内容 |
|---|---|
| 困境 | 一座活着的桥要收过桥费，小人必须在沙漏漏完前把货送到对岸。桥故意垮掉一半，还在讨价还价。 |
| 本关露出芯片 | **6 个**：无限长、复制、时间慢、黏、变硬、变重 |
| 参考解法（三条**正解**，互不相同） | ① **靠长度**：长条 → 变硬 + **无限长** → 一次跨过整条河，无视垮掉的那一半。<br>② **靠数量 + 焊接**：团块 → **复制 + 黏** → 三块紧贴生成、落地即焊成**一块整板**，走板过河（比①更稳、不侧翻；代价是宽度吃地方）。<br>③ **靠时间**：长条 → 变硬 + **时间慢** → 沙漏照常漏，但全场**刚体**（垮塌的桥板、飞来的碎块、桥的咬合部件）速度 ×0.3 持续 3 秒，玩家在这 3 秒窗口里把板搭稳、走完最后两步。 |
| R1 裁定（制作人） | **「时间慢」只作用于刚体，不影响沙漏。** 沙漏是计时器，不是刚体，因此解法③**不是**「把沙漏也拖慢来买时间」，而是「把 3 秒物理时间拉成约 10 秒操作时间」——代价是你必须在沙漏只够走一次的窗口里一次做对。**它是正解之一，不是彩蛋。** 原文中「需谨慎 / 待标定沙漏是否受影响」的表述已作废。 |
| 三条路径为何互不相同 | ① 用**长度**绕过缺口；② 用**数量与焊接**一次成型一块板；③ 用**时间缩放**延长操作窗口。三者对应第 3 章学到的三种不同手段，没有一条是另一条的变体，也不共用同一套判定。<br>**验收口径（R1 的判定不许只看纸面）**：三条路径必须**玩家实际耗时同量级**才算真的三条。已知敏感点：② 要选落点，比 ① 多花约 1–2 秒。<br>**处置已定死（不留选项）**：若实测 ② 明显更慢，**就把 ③ 提上来、② 降为隐藏解法**，同时去调 ② 自己的生成代价；**禁止为救 ② 而放长沙漏**——沙漏被三条路共同约束，松一条等于把另外两条一起放松，那是修症状、坏可解性。标定顺序也不许反：**先测三条路径的实际耗时，再定沙漏时长**（否则沙漏会按最快那条路定，②③ 直接变不可能）。 |
| ② 的代价是真的（不是纸面代价） | 窄处用 ② 会真的退化：空间不足 → **垂直堆叠成一根柱子** → 再不足只生成 2 块。**两种退化必须各给一句反馈，否则他会以为「复制有时候不灵」**——见附录 A 操作反馈台词位（`tooNarrow` / `onlyTwo` 两句分开）。<br>注意 `tooNarrow` 的产物是**塔不是桥**：它在关7 的河上是无用的，这不是"效果打折"而是"给错了东西"，台词要按"你给了我一根柱子"来说服玩家，不能按"少了一块"来说。 |
| UI 暗示（时间慢期间） | 怕玩家以为「时间慢了沙漏也该慢」。所以「时间慢」生效的 3 秒里：**沙漏保持正常流速，并套一圈高亮描边 + 一粒沙掉得比平时「响」**（画面其余部分转冷色调、略拖影）。玩家看到的是「全场都慢了，只有它在赶」——用对比代替解释，不加一个字。 |
| 自由造物槽在说什么 | 桥会跟造物讨价还价、索要贿赂；造物可以用名字"支付"（名字只影响台词，不影响判定）。 |
| 失败会怎样 | 时间到，货被桥扣下当过桥费。小人不生气：「我用一车萝卜换了一句谢谢。」萝卜变成桥上的装饰，永久留着。 |
| 笑点落点 | 桥收「谢谢」当收据；收据上盖着宇宙公章。 |
| 难度 | 4 |

## 六、难度曲线（每关新增的**认知变量**，不是「更难」）

| 关 | 新增认知负担（多出来的那一个变量） | 变量数 | 玩家需要的思维动作 |
|---|---|---|---|
| 1 | **零**：只学「画 → 落地 → 生效」一条因果链 | 1 | 相信笔 |
| 2 | **落点决定成败**：同一种"往下压"，落在南瓜悬空的那半边 → 翻下去；落在靠岸的那半边 → 什么都不发生。形状只改手感和方式（压 / 滚 / 撞），不改成败 | 2 | 选落点 |
| 3 | **能力改变规则**：同一形状 + 不同能力 = 不同结果 | 3 | 选能力 |
| 4 | **配对**：两个能力相乘，且其中一个单独用是废物 | 4 | 做加法 |
| 5 | **作用对象从我方转向环境/敌方**：能力不只用在自己身上 | 5 | 换个对象用 |
| 6 | **复合缺口**：两个条件必须由同一个造物同时满足 | 6 | 一次满足两件事 |
| 7 | **时间压力**：规划时间被压缩（沙漏只在对的时机开始漏） | 7 | 边想边做 |
| 8 | **深度预判**：缝太深，必须先想清后果才敢放手 | 8 | 先猜后做 |
| 9 | **约束下的组合**：多阶段 + 不能命名（不能靠名字自我暗示）+ 在全作通用的「单造物能力上限 2」里做选择 | 9 | 在限制里复用全部积累 |

> 每关**只加一个**变量；旧变量全部保留（形状→形态映射永久有效、自由造物槽不清空）。芯片面板按关卡轮换、数量见第三节节奏表——数量增长本身不构成难度增长，难度只来自上表的认知变量。这是「从易到难」的唯一可执行定义。

## 七、全年龄适配（同一关如何同时服务 6 岁与 30 岁）

| **文案双层**：大字是白话（6 岁懂）+ 小字是吐槽（成人才笑） | 只看大字和动作 | 只为小字留下，记住审计员那句公文腔 |
| **命名不判错**：孩子写「阿巴阿巴」也照样生效，只影响台词 | 写什么都行，立刻有反馈 | 认真起名的人会得到更好的台词，形成自我奖励 |

## 九、语音台词表（R4）· 含「语音 / 纯文字」判据

### 9.1 判据（写死，后续所有文案按此执行）

**进语音的四个条件（必须同时满足）**
1. **字数 ≤18 字**（按朗读字数计，**含标点**——Web Speech 会在标点处停顿，长句会拖成两口气，破坏笑点）。
2. **只在这些时机**（6 类，穷举）：关卡开场 / 首次成功 / 连续失败 2 次 / 隐藏解法触发 / 章节盖章 / 终局。
3. **低频**：一次触发一句；同一句在整局内最多重播 2 次；两句之间至少 4 秒冷却，避免叠音。
4. **说话人已存在于场景内且已分配音色**（角色 = 农夫 / 南瓜 / 水泵 / 小人 / 鱼 / 守卫 / 活桥 / 审计员 / 鼹鼠 / 章印 / 造物）。

**只走文字的时机（一律不朗读）**
- **教程与操作提示**：画布提示、能力芯片说明、三级提示阶梯的**全部三级**（第 1 级台词暗示 / 第 2 级高亮 / 第 3 级轮廓演示）。理由：玩家需要反复回看，语音会撞车且吵。**第 1 级是纯文字**——它不在 9.1 的 6 类语音时机里（那 6 类是穷举），别把"失败暗示"和"连续失败 2 次的通用鼓励"混成一件事：后者进语音，前者不进。
- **界面与系统文本**：命名输入、门卫登记簿、罚单、结算称号、设置项。
- **环境一次性文字**：路牌、投诉信、公章等静态文字（写在场景里，玩家自己会读）。
- **超过 18 字的任何文案**：压不到 18 字就拆成两句短句，或降级为纯文字，**不许硬读**。
- **对玩家操作的即时反馈**：自交笔画判定后的「你这个结……」、造物落地时按几何属性念的形状吐槽、芯片点击反馈。理由：高频、贴脸、打断操作，最容易和语音撞车；且这类反馈出现时玩家正盯着屏幕，不需要靠听。
- **连续失败第 3 次的答案演示**：纯文字 + 轮廓虚线，避免语音抢走玩家的注意力。

> 一句话记忆：**情绪落点进语音，操作说明走文字。** 语音只负责「让人笑」，不负责「教人玩」。
>
> ⚠️ **验收口径**：语音是增强，字幕是承诺。所以「这句没响」**不是 bug**，只要字幕已经出现在屏幕上——`speak()` 的合法返回包含 **延后（45 s 内排队）** 与 **永不出现（被拦/过窗作废/无语音引擎）** 两种，验收时都算通过。反过来说：**字幕没出才是 bug**，因为那是玩家唯一的信息通道。

### 9.1b 第 1 章语音密度与丢弃优先级（设计侧裁定）

第 1 章 3 关 5–7 分钟共 6 句语音（3 开场 + 3 首次成功），约每 60 秒 1 句；关1 开箱更密（0–3 s「你是谁？」+ 22–28 s「能踩。它没抱怨。」= 25 秒内 2 句）。**不违规，但这正好落在评审看的前 30 秒里，是最可能被听成唠叨的一段。** 执行细则见 `docs/audio-spec-v2.md` C1–C3，设计侧只裁定取舍方向：

1. **关1 的 2 句必须保留**——开箱要让人立刻知道「这游戏有声音」。**第 2 句在盖章音效之前播完**（对齐 `decisions.md` D8-A1）；若剩余时长 < 该句朗读时长 + 0.3 s，**整句丢弃、只留盖章**。**不允许把第 2 句挪到盖章之后**——延后会把「首次成功」的即时兑现挪出成功瞬间。关1 前 30 秒的钩子是「你是谁？」（好奇）+「能踩。它没抱怨。」（兑现），后者必须贴着成功那一刻。
2. **冲突时「首次成功」优先于「开场」**（里程碑优先于氛围）。这条我认同。
3. **但开场句之间不许一律先丢开场**——按**信息量**排丢弃顺序：**先丢关3 的开场，再丢关2 的开场**。
   - 关3「你踩不动我。别试了。」= 纯挑衅，**零信息**（画面已经写明他踩不动），丢了不损失任何东西。
   - 关2「它不肯走。它是方的。」= **含机制信息**（它不会自己走 + 它是方的所以推不动），是关2「落点决定成败」的第一句铺垫，尽量保。字幕/画面能兜，但它是本关的教学台词，优先级高于纯吐槽。
4. **关4 之后不需要额外约束**：每关约 2.4 分钟 2 句，语音占用约 5.7%，不会唠叨。
5. **同一说话人的间隔用「延后」而不是「丢弃」**（C4）：同音色 45 s 内不重复（跨关成立），默认手段是把后一句往后挪，台词不许为了守间隔被牺牲。只有两种情况改为丢弃：延后会撞上本关后续语音；或已延后超过本关时长的一半（语境已过）。**C1（关1 两句连响）是 C4 的唯一豁免。**
6. **说话人不在画面内不起播**（C5）：`speaker.onScreen === true` 才允许起播，否则会被听成系统旁白、笑点变噪音。**关3 开场句改为「水泵首次入画」事件驱动**（不是关卡进入时触发），认知与台词同步。
7. C1–C5 的执行细则与硬常量（含 45 s 的实测值）、**【C.1】C4/C5 与台词配额三者的优先序**（先过 C4/C5 → 配额预检 → 扣费；**语音额度的唯一扣费点在 `onstart`**；C5 是挂起不是丢弃；已起播被打断算消耗）、**【C.1b】"打断"必须拆成两个动作**（未起播 = **抢占**，不扣费、优先手段；已起播 = **终止**，已扣不退，**只允许"语义已过期"一个理由**；另有**场景边界强制终止**，防音画脱钩——关末三句串行 6.5 s 对 3 s 切关动画就是反例），以及 **【C.2】两套额度必须分离**（"文本出现几次" ≠ "语音额度"；只出文字的台词**不占**语音额度；**两套额度各跟自己的交付器走——文字额度在字幕真正显示时扣，语音额度在 `onstart` 扣；字幕显示了但语音被 C5 拦下，文字额度照扣**），均以 `docs/audio-spec-v2.md` 附录 C 为唯一权威，本文不复述数值。<br>⚠️ **本作台词一律不许说成"不可打断"**——那是把"抢占"和"终止"合成一个动作的错误简化。正确写法只有三种：这个 id **可否被抢占**、**可否被终止**、**切关时是否强制终止**。而这三列**不由文案侧维护**：**级别由「时机」自动推出**（首次成功/盖章/终局 = 1 级｜关卡开场 = 3 级｜隐藏解法/环境吐槽 = 4 级；**唯一例外：配了逐句稀缺额度的一律升 2 级**），见 C.1b 表。所以文案只声明两件事：**① 属于六类时机中的哪一类；② 有没有配稀缺额度、几次**（整局还是每关）。两个都不声明 = 纯文字，不进语音。

### 9.3 终局「造物自己说话」那句（与音频侧对齐）

**裁定：不做模板拼装，只做「单句固定句式 + 1 个名字插槽」，全剧只播一次。** 理由：`speechSynthesis` 拼接多段会露出接缝，句式的可听性比句式数量重要得多；这句的功能是情绪收束，不是多样化。

- **固定句式（唯一）**：`「它叫〔名字〕。它有用。」` —— 名字为空或玩家从未命名时，读降级版 `「它没有名字。它有用。」`
- **插槽长度硬上限：4 字**（命名输入框直接限 4 字）。这样最长实例 = 「它叫」（2）+ 名字（4）+ 「。它有用。」（5）= 11 字，恒 ≤18，音频侧不需要做任何长度分支。
- **播放次数**：1 次，无重复、无冷却问题。
- **降级规则**：名字含不可朗读字符（表情、符号、纯标点）时，只念其中的文字部分；文字部分为空则走降级版。
- **不朗读的配套内容**：罚单 / 签收栏里那个歪歪扭扭的小人 / 沙盒解锁提示（全是界面与环境文字，见 9.1）。

## 十、首关开箱设计（30 秒生死线）

| 时间 | 屏幕上发生什么 |
|---|---|
| 0–3 s | 黑屏。一笔手绘线条自己画出一只眼睛，睁开；镜头拉远——是农夫的脸。他说：「你是谁？」（**语音**；全屏唯一文字，4 字） |
| 3–8 s | 画面往下一沉，露出造物簿（手绘质感画布）。上面只有一行：「他过不去。画点什么。」**没有按钮、没有菜单、没有教程文字**。 |
| 8–15 s | 第一笔随便画，画布全盘接收、不判错、不设笔数上限。落笔瞬间有纸笔摩擦音。 |
| 15–22 s | 造物落地 → 头顶浮出一颗**灯泡**（本关面板只有「变硬」这 1 格，不弹面板）。点灯泡，造物变硬并有金属声。 |
| 22–28 s | 农夫走过去踩上、过沟。他回头说：「能踩。它没抱怨。」（**语音**）盖章音效：「实习期 · 第 1 件作品」。 |
| 28–30 s | 造物簿右上角第 2 格亮起（「会滚」，下一关才可用），不解释、不朗读，放在那里等玩家自己发现。 |

**硬指标**：30 秒内必须发生「我画的东西真的动了，还被人用了」这一件事。全流程单屏文字 ≤ 25 字。手机竖屏优先，画布占下半屏 45%。

## 附录 A · 形状 → 形态映射（关卡可解性的前提，供主程序承接）

> ⚠️ **判定顺序、阈值、失败分支与退化链，一律以 `docs/tech-baseline-v1.md` §5 为唯一权威，本文不复述、不另立一套。**（对齐 `docs/decisions.md` D9：同一事实只能有一个载体——两份都写，主程序改一份不改另一份，QA 就无法判定谁对。）
> 本附录只保留两样东西：**每个形态在游戏里干什么**，以及**为什么必须这么判**（设计意图）。改动设计意图请找我，改动顺序 / 阈值请找技术架构师。

**形态的职责（不是判定顺序，只是「判成这个东西是用来干嘛的」）**

| 形态 | 行为基调 | 关卡里的用途 |
|---|---|---|
| 松散堆 | 多块小刚体，会散 | 台阶原料（关4 加变硬、关5/关7 加黏） |
| 绳 | 柔性链（铰接），**只能受拉、不能受弯** | **v1 不实装**（`ENABLE_ROPE = false`）：零必需路径、成本最高、铰接链易抖，阶段 2 先落到团块兜底，阶段 3 有余量再启用。保留此形态的语义描述是为了将来不返工 |
| 梁 | 长刚体，两端可支撑 | 桥、滑道、承压板（最常用）。**不再充当"杠杆"**——全作没有一关以撬动作正解（见关3 销账条）。两笔相接但极为细长的也算梁，只是接缝处留一道铅笔接痕 |
| 容器 | 中空，可装水/装物 | 舀水、装鱼 |
| 颗粒 | 质量极小 | 投掷物、诱饵 |
| 轮 | 圆柱刚体，可滚 | 轮子、滚石、球 |
| 团块 | 软刚体，可堆叠、可压 | 垫脚石、压舱、诱饵（**兜底形态**，任何画不准的东西最后都落到这里） |

**四条设计意图（判定的「为什么」，不是判定条件）**
1. **先看有没有孔，再看闭合形态**：孩子画「圈里点个点」很常见，判成容器比判成轮更有戏（能舀水、装鱼）。**有孔优先，因为孔是玩家的明确意图。**
2. **画成闭合的圈，永远不许变成一座桥。** 这是关1 的教学立意——「长条**没画完**（未闭合）才有梁」。否则玩家在沟上画一个细长的圈就能白拿一座桥，整关要教的东西被绕开。**设计师让玩家占便宜，只能让在「兜底也能过」上，不能让在「投机白嫖」上。**
3. **自交笔画按外轮廓处理，不做交点分割**：画一个「8」字，物理上就是它外侧轮廓的一坨东西。这是**故意接受的不精确**——玩家画乱了不该被惩罚，但也不该因此变强。它必须被当成笑点而不是 bug，见下方台词位。
4. **「细长」优先于「多笔」**：两笔首尾相接、画得很细长的，玩家心里的目标本来就是一根梁；把他判成会垂的东西，等于因为多画了一笔就惩罚他。**不惩罚多画一笔，也不奖励投机闭合**——这两条是同一枚硬币，方向一致才叫规则，否则就是补丁。

**由这几条意图推出的三条设计侧硬约束**
- **兜底优先，绳押后**：v1 不实装绳，多笔相接且略胖的一律落到**团块**。关1 的可解性不靠绳成立——团块 + 变硬 = 硬块垫脚，是附录 A 铁律本身就保证的路。**如果阶段 3 启用绳，则「绳 + 变硬」必须真的能承载（农夫单人重量走得过去、不塌不折）：承载的**成立与否**由「变硬 = 形变系数置 0 + 可承载重量」的定义推出、不是待标定项；**承载到什么程度**（垂度判据）仍属实测标定。撑不住按实现缺陷修，不改关卡（对齐 `decisions.md` D7 / D9）。**
- **变硬不自动拉直**：已下垂的东西就冻在下垂的姿态上（「冻成什么样就是什么样」）。自动拉直等于篡改玩家画的形状，违反 D2「只读形状」。
- **「无限长」只放宽梁 / 团块的笔画长度**，不在柔性链形态下生效（否则玩家会以为能拉成藤蔓）。本版 9 关**没有任何关卡需要长绳**，不为绳扩预算。

**操作反馈台词位（一律纯文字，不朗读）**

| 触发 | 说话人 | 台词 | 字数 |
|---|---|---|---|
| 自交笔画（判成外轮廓坨状） | 农夫（关1–3）/ 鼹鼠评论员（关4 后） | 「你这个结……算了，像个团子。」 | 14 |
| 两笔首尾相接、细长，判成带接痕的梁 | 农夫（关1–3）/ 鼹鼠评论员（关4 后） | 「你这是两笔接的，我看见了。」 | 13 |
| 变硬作用于**已下垂的软团块**（冻在下垂姿态，v1 用这个触发；阶段 3 启用绳后扩展至绳） | 农夫 | 「它现在是一条很没精神的桥。」 | 13 |
| 复制在窄处退化：空间不足 → **垂直堆叠成一根柱子**（技术侧上报 `degraded === 'tooNarrow'`） | 农夫 | 「太窄了。它把自己堆成一根柱子。」 | 15 |
| 复制退化：空间只够生成 2 块（`degraded === 'onlyTwo'`） | 农夫 | 「这儿太窄，塞不下三个。」 | 11 |

- **不朗读理由**：五条都属于「对玩家操作的即时反馈」，时机不在 9.1 的 6 类语音时机内，且会被反复触发——高频、贴脸、会与语音撞车。按 9.1 判据一律走文字气泡。
- **为什么退化要分成两句**：两种退化的**物理结果不是一回事**——`onlyTwo` 是「少了一块」（效果打折），`tooNarrow` 是「**变成了一根柱子**」（产物根本不是玩家要的东西）。用解释"数量不够"的话去解释"给了你一根柱"，玩家会问「那这柱子有什么用」。**台词要解释玩家实际看到的东西，不是解释系统内部的分类。**
- **通用判据（这一条比上面两句更重要）**：**任何「玩家要求了 A、系统给了 B」的情况，都必须有一个可见或可听的理由**，否则玩家会把「规则」读成「bug」，并且**从此绕开那个能力**——他不会来报错，他会默默不用。本作现有的静默降级点只有复制退化一处（`BodyBudget` 满也有台词覆盖），以后每出现一处都按这条加反馈。

**落地形状分岔台词（全作唯一"按几何属性分岔"的台词，一律纯文字、不朗读）**

> **这一张表是给主程序的闭集**：造物落地后按判定结果取一句话，**表外不许自拟**。选它的理由：这是全作唯一需要按几何属性分岔的地方，也是最容易被"顺手写一句更好的"改坏的地方——而玩家在这一秒正要判断"我画的东西变成了什么"，台词必须和判定一致。

| 判定为 | 说话人 | 台词 | 字数 |
|---|---|---|---|
| 梁 | 农夫（关1–3）/ 鼹鼠评论员（关4 后） | 「这东西能踩吗？」 | 6 |
| 轮 | 同上 | 「圆的。它会自己跑。」 | 9 |
| 团块 | 同上 | 「你是不是想让我踩这个？」 | 11 |
| 松散堆 | 同上 | 「你画了三个。我只有一双脚。」 | 13 |
| 容器 | 同上 | 「这玩意儿能装东西？」 | 9 |
| 颗粒 | 同上 | 「这么小？吹口气就没了。」 | 12 |

- 同一句在整局内不重复超过 2 次（超过就静默，不要为了填满而换同义句——换句会让玩家以为形状判成了别的）。
- **例外：跨关通用兜底句（`common_fail2` 一类）按「每关 2 次」计，不是整局**。理由：它是兜底，整局额度会被前一关吃光，后面的关就**没有兜底**了——兜底句一旦用完，"说不出话"的那一面就裸着。形态落地台词、各关专属失败暗示仍是整局 2 次。
- **凡是"以后一定有人手滑"的规则，做成断言而不是注释**：禁用话术、闭集条数、"已删除的 id 不得回来"，都写成测试（主程序侧已落地：删掉的 id 反向断言"必须不存在"）。注释会被绕过，断言不会。
- **两个默认值里选一个时，选"错了会被发现"的那一侧**：能被听到/能报错的默认值，优于沉默的默认值。例：台词"未声明"的默认必须是**纯文字**——若默认进语音，漏声明会多念一句（听得到，好修）；若默认"没声明就静音"而实现按文字走，就变成只有字幕没有声音（无人报错，只能靠事后察觉）。**能报错的错误优于沉默的错误。**
- 说话人**不在画面内不起播**（对齐 9.1b 的 C5，虽然这里是文字不是语音，理由相同：话必须看得出是谁说的）。

> **设计铁律**：任何关卡的必需解法都必须存在**至少一个「团块（兜底形态）+ 某能力」**的可行路径。这样玩家画得再丑也不会走进死路——「画得丑」只能让他多花 30 秒，不能让他过不了关。主程序侧的三级退化（拆凸失败 → 凸包 → 矩形 → 圆形）保证判定永不抛错，与这条铁律同向。

**「设计意图」也有属名（本次回顾补上的最重要一条）**

关2 今晚返工四轮（D21 → D23 → D25 → D26）的根因，不是谁不认真，而是**设计意图没有验证方**：我写"梁碰不到南瓜"，主程序把它实现出来、测出"梁必然扫到"，中间**没有任何一方被指定去问"这条意图在物理上成立吗"**。我只验"读起来对不对"，他验"跑起来通不通"，**两条都通过，合起来是错的**。

| 列 | 是谁 |
|---|---|
| 产出方 | 我（设计意图 / 判据 / 台词） |
| 消费方 | 主程序（实现）、audio-director（台词通道）、tech-architect（物理可行性） |
| **验证方** | **实测矩阵，不是我**——`tests/*-passable.mjs` 这类"可过性/终态"矩阵是设计意图唯一算数的证据 |
| 断言位置 | 每关至少一条能红的实测断言；**"我觉得这对"不算证据，"我在灰盒里玩不出来"是证据** |

推论（写给我自己）：**凡是我说"这个设计上成立"而没有任何人能测的地方，那就是一个没人属名的交界。** 遇到这种地方正确做法不是我再说一次"成立"，而是先要一个能红的测法；拿不到测法，就把它降级成"待标定"，不许当结论用。

**"成立"必须有保质期**（与 audio-director 的 F.1 通则 3 配套）：一条意图写下时没人能测，可以；**但如果到实现阶段仍然没人能测，它就已经不是"待验证"，而是"没人管"**——待验证的会有人去验，没人管的会一直在那儿。所以每条设计意图要标一个**"何时必须有测法"**：到点仍没有测法的，自动降级 `[待标定]`，**不再作为实现依据**（不是被否掉，是不许再被当结论引用）。

当前已按此降级的例子：第七节「卡住不超过 40 秒」——机器测不了，只有真人小样本能测，**标 `[待标定]`，不得当验收标准引用**。

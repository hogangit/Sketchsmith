## 二、玩法与核心循环

玩家是「造物主」：在造物簿上**手绘一个形状**，从能力栏选一种**预定义能力**贴上，造物从天而降落入手绘世界，用物理规则解决关卡目标。

- **核心动作**：画线 → 选能力 → 看它落地后的物理表现 → 调整再画。
- **5 个脚本化关卡**（难度递增）：顶南瓜过关 / 搭桥送物 / 压板变重 / 弹床弹射 / 水与浮力，每关自带一句**白话目标**，旁观者 30 秒内看懂在玩什么。
- **沙盒「造物园」奖励**：通关后解锁，画什么留下什么，可自选能力、单条删除、清空——把作品变成玩家自己的手绘动物园。

## 三、差异点（为什么不是又一个"画个坡让球滚进去"）

竞品扫描结论（docs/research.md）：造物/手绘题材在本次赛事**未被占位**，但"画线物理"品类极度拥挤，评审见过太多次"画坡滚球"。本作的差异化：

1. **能力系统而非纯形状**：胜负不靠"画得多像坡"，而靠**给造物赋予什么能力**（变硬/黏/轻/重/弹/长/圆/复制……）。同一笔形状贴不同能力是两种解法——这是"造物主"而非"画师"的定位。
2. **幽默自嘲角色驱动**：一个手绘农夫全程吐槽自己的倒霉遭遇（"梁撑得住。可它够不着南瓜。"），**只讲自己的毛病、绝不评价玩家**——规避温情说教，贴合轻松搞笑的赛事调性。
3. **关卡自带白话目标 + 可演示**：每关一句话说清要干嘛，评委/旁观者零门槛理解，不靠说明书。
4. **脚本化关卡 + 沙盒奖励的双层结构**：前 5 关保证"上手即懂"，沙盒满足"我想要我的世界"——避免纯沙盒"旁观者看不懂在玩什么"的通病。
5. **零依赖单文件交付**：运行时无任何 CDN/后端，一个 HTML 双击即玩，弱网/离线/比赛机器都能跑；美术为手绘墨线 + 纸张质感，音频 17 个音效 + 语音调度全部程序合成零文件。

## 四、技术亮点（评委可能关心的）

- **真实手势链路已端到端验证**：用 CDP 派发真实 touch 事件走完整 `pointerdown→采样→归组→生成造物`，实测 2px 采样门禁、事件链完整、关1 真实通关。
- **性能降级被验死**：`perf-governor` 测试 6/6 覆盖物理降帧/好帧清零/三档渲染开关语义；headless 桌面三档 p50 16.6–17ms 在 60Hz 预算内。
- **音频解锁结构正确**：首次 `pointerdown` 同步解锁，队列兜底前 3 条音效，避免"第一笔没声音被判没做音效"。
- **可复跑的质量门禁**：13 道构建门禁 + 7 套测试（core 20/20、sandbox 7/7、audio-sfx 9、perf 6/6、farmer 5/5、l4×2）全绿。
- **完整开发文档**：`docs/` 含决策记录、竞品扫描、技术基线、美术规格、音频规格、关卡设计，可追溯每个设计取舍。

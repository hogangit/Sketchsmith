# 《我是造物主》视觉打磨规格 · art-polish-spec v1.0

> 立项依据：`docs/decisions.md` **D5（手绘纸感 / 单色墨线 + 纸张纹理 + 能力生效才上色）**。
> 目标平台：430×932 竖屏 Canvas 2D，低端机稳 60fps。零外部素材（无图片 / 无字体文件 / 无音频）。
> 本文是**施工规格**，不是方向稿：每个元素给到「色令牌 + roughjs（或纯 canvas）参数 + 坐标锚点 + 层级 + 静态/动态 + 降级 + 验收点」，主程序可照抄。
> 记录：美术总监 甄塑之 · 2026-10-27 · 评审用。

## 施工摘要（先看这 6 行）

1. **不动 D5**：画面仍是"一张纸上的墨线画"，主题差异靠**剪影 / 线密度 / 极淡晕染**承载，不靠填色卡通。
2. **主改一处**：把 y=300→513 的**土体剖面**（全屏最灰最平的一块）做厚——表土 / 层理 / 碎石 / 根须 / 潮斑。这是投入产出比最高的单项。
3. **静态优先**：所有新布景进 `drawStatics` → `staticLayer`（关卡切换只跑一次），**每帧增加 0 次 rough 调用**。动态只留 ≤6 类廉价笔触（风 / 水光 / 涟漪 / 微粒 / 布幡摆 / 农夫细节），全部纯 canvas，禁用 rough。
4. **给农夫加 4 个"活"细节**：挠头、看向造物、跳跃姿势、帽檐风动。仍是墨色火柴人，不填色。
5. **每关 5 个新程序化元素**，全部从色板取色，允许饱和面积 ≤3%。
6. **三道红线不动**：物理 / 判定 / 关卡几何（terrain / props / plates / goal / spawn / guides 的现有数值一律不改）。新增布景 = 纯装饰，无物理体。

## 一、风格定义（D5 细化，不是推翻）

**一句话**：像一本下乡农技员的旧工作笔记——米黄纸、暖墨线、少量水彩般的干淡晕染；只有"玩家造物生效"与"目标物（南瓜）/ 芯片激活"才允许出现饱和色。

### 三条铁律
- **R1 线是主角**：所有地形、剪影、远景、水面、风，都用墨色线（I 系列）或极低饱和淡彩（A/E 系列）画；**禁止用彩色线**画布景。
- **R2 饱和配额**：任何新增填充色的 **HSL 饱和度 ≤ 30%、明度 55–92%**（=纸感淡彩）。唯一例外是"允许饱和四类"（见下），且四类**整屏覆盖率 ≤ 3%**。
- **R3 颜色不作唯一信息载体**：芯片选中状态、失败提示、可交互项，除颜色外必须叠加**形状/下划线/勾/虚线框**等第二通道（色觉差异下仍可辨）。

### 允许饱和的四类（全部 ≤3% 面积）
① 能力生效的造物（绿）② 芯片选中态（绿）③ 南瓜（橙，目标物）④ 布幡/集市小道具（赭红，仅 L2/L3 小面积）。

### 与 D5 的关系
D5 原文"只有能力生效时才上色"过于绝对，本条细化为：**氛围色（天空、土、水、theme 晕染）以 ≤0.14 alpha 的极淡 wash 呈现，读起来仍是'纸上的颜色'而非'填充块'**；高饱和仍严格留给"能力生效"。主题色因此不破坏风格连续性。

## 三、全局项（4 类通用质感 + HUD）

### 3.1 天空与远景层次　【Z0–Z2 · 静态 · staticLayer】
- **天空渐变**（替换现 `#e8dfca→#f2ead8`）：竖向 4 档，保证顶部浅（深色标题可读）。
  `0→P2 #ECE4D2` / `0.55→#E9DEC6` / `0.88→#EFE0BE`（近地平最暖）/ `1(y≈300)→#F1E6CC`。
- **地平线晕染**：贴地表线 y=300 上方 46px 画一条横向渐变带（顶 alpha 0 → 底 `A1` L1 / `A2` L2 / `A3` L3 对应主题），高 46px、全宽。给天空"接地"。
- **远山三层**（升级现 2 层）：同一三角路径函数画 3 层，alpha `0.16 / 0.24 / 0.34`、色 `A4`；仅最近一层加 `I4` 轮廓描边；最近山内散点 6–8 个树点（1.5px 墨点）。层间基线错开 6–10px 制造纵深。
- **验收**：静止两帧整屏像素 diff=0（已进静态层）；缩到 30% 缩略图天空不再是"一块灰板"，能看出一条地平线与 3 层远近。

### 3.2 云　【Z2 · 静态（远云）+ 动态（近云 1 朵可漂，可选）】
- **远云带**：2 条扁横云 `rgba(255,255,255,0.28)`，宽 90–140、高 6–9，圆角椭圆叠 2 个；贴 y 150–200。
- **近云**：1 朵"描边云"——不填色，只用 `I4` 勾轮廓（3 个圆弧连成），体现"墨线画出来的云"。位置 x 250–360 / y 150–186。
- 降级 low：只保留远云带 1 条，删近云描边。
- **验收**：近云无填充、仅线条，与 D5"墨线"一致；三类元素（远云带 / 近云 / 飞鸟）在 25% 灰化下仍可区分层次。

### 3.3 地形纹理升级（**本项为全局最高优先级**）　【Z3–Z5 · 静态】
现有土体只有"单斜线填充 + 9px 表土带"，读起来是纯色板。升级为 5 层叠加（全部在 `staticLayer` 一次画完）：
1. **块底色** `P1`/`E0`（沿用）。
2. **表土暗带** 顶部 `E1`，高由 9→12px；下方再叠一条 3px 的 `rgba(90,80,64,0.14)` 过渡。
3. **水平层理**：每 16px 一条 `rgba(110,96,70,0.12)` 细横线（只在中/高档；低档删）。
4. **斜向土纹**（保留现 hachure 思路）：间距 13、`E2`、lineWidth 1；**仅 mid/high 档**（low 删，改用层理替代，避免糊）。
5. **碎石 + 根须 + 潮斑**：在土体内随机散 8–12 块碎石（椭圆 3–5px，`E4` 填充 + `I2` 1px 描边）、每条根须 2–3 段折线（`rgba(96,86,62,0.5)`）、2–3 团 `rgba(110,96,70,0.10)` 潮斑（大椭圆）。
6. **地表草簇**：沿地表线 y≈300 每 30–46px 一簇，3 笔（`I3`）上挑；密度左右两半随机。
- 用 `nextInkSeed()` 做确定性随机（同关卡每次布局一致）。
- 降级：low = 只保留 ①底色②表土带③草簇；mid = 加层理+石+根须（删斜纹）；high = 全开。
- **验收**：土体在 30% 缩略图下**不再是纯色板**，能数出 ≥3 个可辨纹理层次；同一关两次进入布局完全一致（确定性）。

### 3.4 造物簿纸面　【Z9 烘焙 + Z10 动态】
- **烘焙 paperLayer**：把现在每帧执行的 `drawPaper`（填充 + ~19 条格线 + 装订双线 + 边框）**移到第二个离屏 `paperLayer`，关卡切换时画一次**，主循环 `blit` 后再画用户笔迹。省下每帧 ~25 次 path（直接抵掉新增动效的开销）。
- **质感追加**（烘焙层内）：
  - 顶部微亮→底部微暖的竖向 wash（`#F8F4E8 → #F4EEDF`）。
  - 页眉撕口/毛边：顶边 6–10 段极短墨点（`P5`）模拟毛边。
  - 1–2 处"旧墨渍"：`rgba(150,96,74,0.05)` 圆斑（半径 20–40，贴非书写区）。
  - 书页与场景分隔：BOOK_TOP 处 6px 竖向渐变 `rgba(90,80,64,0.10)` 内投影。
- 格线 / 装订线 / 页码 / 边框：保持现有数值不动（已评审通过）。
- **验收**：`drawPaper` 不再出现在每帧路径里（grep 帧循环无 drawPaper 直接调用）；纸面在截图缩图下与场景有明确"这是一张纸"的分隔。

### 3.5 HUD 芯片手绘化　【Z11 · 动态（低频）· 纯 canvas】
> 几何（`chipRect` 66×34 / gap6 / y8、`headerButtonAt` 命中区）**一律不动**，只改视觉。

- **手绘边框**：不用直线 `roundRect` 描边，改"双趟抖动"——同一圆角矩形画两遍，第二遍整体偏移 (±0.5,±0.5)、alpha 0.5，再加 4 个角"提笔小尾巴"（每角 4px 短线，`I0`）。3–4 chip 共 ~30 笔，每帧可接受。
- **选中下划线（第二通道）**：选中态在文字下画 3 段抖动横线（`C0d`），**保证不靠颜色也认得出选中**（R3）。
- **无衬线检测**：low 档去掉双趟抖动，只留单遍 + 下划线。

**芯片状态视觉清单（只描述视觉差异，交互逻辑交主程序）**

| 状态 | 触发（交互侧） | 填充 | 描边 | 文字 | 第二通道标记 |
|---|---|---|---|---|---|
| 默认(off) | 未选中、本关可用 | `P0` | `I3` 手绘双趟 | `I0` 600 | 无 |
| 悬停/按下 | pointer 按下未抬起 | `P0` + 1px 下发丝影 | `I2` 加深、整体内缩0.98 | `I0` | 轻微下移 1px（触感） |
| 禁用(disabled) | 本关不提供该能力 | `P0` @40% | 无抖动、淡 `I3` | `I3` | 无（不可点） |
| 选中(armed) | 该能力已挂到造物/待用 | `C0` | `C0d` | `P0` | **下划线 3 段 + 右上小勾** |
| 高亮提示 | 失败后引导关注 | 默认态 | 外扩 2px 虚线框 `C3` | `I0` | 虚线框（闪烁交动效，此处只给静态样式） |

- **标题 / 副标题 / 重来 / 声**：保持现有字体与色（`I0`/`#7a6f5e`）；"重来 / 声"两按钮也套用手绘双趟边框（与芯片同一语言）。
- **验收**：5 个状态在 25% 灰化下**仅凭形状**即可区分选中与非选中；芯片矩形命中区与 `chipRect()` 完全一致（点击不偏移）。

### 3.6 纸面颗粒 + 暗角 + 边影　【Z0 顶层 · 静态】
- **纸颗粒**：确定性撒 ~160 个 1px 点（`rgba(60,52,40,0.05)`）铺满场景带 0–513，给"纸的牙口"。
- **暗角**：径向渐变（中心透明 → 四角 `rgba(60,50,36,0.06)`），一次性，增强"画面聚焦"。
- **降级**：low 删颗粒（保留暗角）。
- **验收**：整屏不再"发闷发平"；颗粒在 100% 下可见、不影响文字可读（正文区不得撒点）。

## 四、逐关场景元素（每关 5 个新程序化元素）

| L2-5 | 收货口棚布升级 | 焦点 | 现 funnel 加：褶线 4 条（`rgba(90,80,64,0.35)` 放射）、边缘扇贝 6 弧、`C5` @.10 微赭 wash | Z4/Z5 | 静 | 仅褶线 | 读成"软漏斗"而非木框 | — |

**L2 动态**：风只做**2–3 条**横向虚线漂移（`rgba(120,110,90,0.35)`，长 24–40，向右匀速+回收），加 1 片飘叶（1 小弧）。复用同一风引擎给 L3 芦花。

### 4.3 关3「踩不动的水泵」水塘　（主题：潮气、芦苇、静水）
| # | 元素 | 类别 | 配方（色 / rough / 锚点） | 层级 | 静/动 | low 降级 | 验收点 | 复用 |
|---|---|---|---|---|---|---|---|---|
| L3-1 | 水面 + 反光 | 环境 | 泵基周围（x≈320–412, y≈380–470）不规则水塘：`W0` 填 + `W2` 3–5 条水平波纹；3 段 `W1` 高光短杠随时间轻微平移（±1.5px 正弦） | Z4/Z8 | 静+动 | 静态水+波纹、高光不闪 | 一眼是"水"不是"地" | 水光复用 |
| L3-2 | 芦苇/香蒲 | 中景 | 水岸 6–7 根：杆（`I3` 竖）+ 2–3 片叶（斜线）+ 香蒲头（1 短粗棒 `E1`）；其中 2 根顶部 ±1.5px 摆 | Z4/Z8 | 静+动 | 静态不摆 | 岸线有"活物" | `草簇`变体 |

| L3-5 | 干裂纹（田裂） | 焦点 | 现"田裂了"区升级为可辨裂缝：主干 1 条 + 3–4 条分叉（`E5` 1px，折线），配 2–3 块翘起土片（`E0`+`I2`） | Z4 | 静 | 仅主干 | 缩图读成"裂开的地" | 裂缝复用 L2 |

**L3 动态合计**：涟漪 2 + 水光 3 + 芦苇摆 2 + 风 2 = ≤9 笔/帧，全部纯 canvas。

## 五、农夫「活」感（4 个廉价细节 · 全在 `drawFarmer`）

> 硬约束：**仍是墨色火柴人**（`I0` 线条 + 草帽米色），不填色、不加五官细节堆砌。`drawFarmer(ctx,cx,cy,opts)` 现签名不变，`opts` 增加 `{ look, state, t, jump }`。`phase`/`face`/`scale` 语义不变。

| # | 细节 | 触发条件 | 配方（在现有 14 行骨架上追加） | 层级 | 静/动 | 验收点 |
|---|---|---|---|---|---|---|
| F1 | 挠头 | 空闲 >1.2s（无造物/等待中），且非跳跃 | 右臂改画：肩(0,-2.6)→肘(-3.5,-6)→头侧(-4.6,-9)；肘部画 2–3 段小弧（半径 1.2，相位随时间），周期 ~0.8s | Z7 | 动 | 视频里"他在想"可读；≤3 弧 |
| F2 | 看向最新造物 | 场景存在活跃造物 | `face` 取造物质心方向；眼睛额外偏 0.6px 朝目标；帽檐下加 1px 短"视线"引导线（可选） | Z7 | 动 | 造物在左则他朝左；与走路朝向不打架（走路优先） |
| F3 | 跳跃姿势 | `actor.jumping>0`（runtime 已有计时） | 双臂上举（两线到 (0,-8) 区）、双腿收拢（短线段抬至 y10）、草帽整体上抬 1px | Z7 | 动 | 能看出"被弹起"而非瞬移 |
| F4 | 帽檐风动 | L2/L3 起风时（风引擎活跃） | 帽檐椭圆外侧 2 点按 `sin(t)*1px` 微抖 + 帽顶 1 抖 | Z7 | 动 | 极轻微、不抢戏；L1 无风不触发 |

- 追加路径总量：常态 0（F1 空闲才触发），最坏 F1+F3 同帧 ≤6 笔 —— 单角色，无性能风险。
- **验收**：录 5 秒 idle，农夫至少有 1 次可见小动作（挠头或帽动）；跳跃瞬间姿势变化肉眼可辨；整体仍是"几根墨线"的火柴人，不出现填色块。

## 六、性能与降级预算（低端机 60fps 的生命线）

### 6.1 现有每帧 rough 调用 ≈ 0
`drawStatics` 末尾仅 1 次空 `rc.rectangle`；布景全为纯 canvas。**结论：rough 预算极宽裕，全部新增布景塞进静态层即可，每帧 rough 增量为 0。**

### 6.2 静态层归属（一次烘焙，关卡切换 invalidate）
| 层 | 内容 | 时机 |
|---|---|---|
| `staticLayer`（现有） | 天空/远山/云/地形体/纹理/草簇/洞壁/木桩/棚布/摊架/泵/裂纹/颗粒/暗角 | `buildWorld` → `invalidate` → 一次 |
| **`paperLayer`（新增）** | 造物簿纸底+格线+装订+页码+边框+墨渍+边影 | 同上，一次；主循环 `blit` |
| 动态层（纯 canvas，禁 rough） | 造物/南瓜/压板（现有 drawBodies）、农夫（+F1–F4）、环境动效（风/水光/涟漪/微粒/布幡摆/涟漪） | 每帧 |

### 6.3 每帧动态路径预算（新增部分）
| 动效 | 上限笔数 | low 档 |
|---|---|---|
| 风（虚线漂移+飘叶） | ≤4 | 0（关） |
| 水面高光闪烁 | ≤3 | 0（静态水） |
| 涟漪环 | ≤2 | 0 |
| 布幡/芦苇摆动 | ≤3 | 0（静态） |
| 漂浮微粒（可选） | ≤6 点 | 0 |
| 农夫细节 F1–F4 | ≤6 | F1/F3 保留，F4 关 |
| **新增合计** | **≤24 路径/帧** | **≤6** |

配合 6.4 的 `paperLayer` 省下的 ~25 路径/帧，**净增 ≈ 0（low 档净减）**。

### 6.4 分档矩阵（对齐 `perf.js RenderQuality`）
| 项 | high | mid（Safari/移动默认） | low |
|---|---|---|---|
| 斜向土纹(2.3#4) | 开 | 开 | 关 |
| 水平层理(2.3#3) | 开 | 开 | 关 |
| 碎石/根须/潮斑 | 开 | 开 | 关（留草簇） |
| rough hachure 填充 | 开 | 关 | 关 |
| 阴影/纸颗粒 | 开 | 颗粒开、阴影关 | 全关 |
| 环境动效 | 全开 | 全开 | 仅农夫 F1/F3 |
| 芯片双趟抖动 | 开 | 开 | 单遍 |

### 6.5 验收
- 430×932、DPR≤2、`low` 档：连续静止 + 动画场景各 10s，帧间隔 p90 ≤ 16.7ms（≥58fps）。
- 关卡切换后首帧 ≤ 2 帧内出画（静态层一次烘焙不卡顿）。
- `RenderQuality.setFill(false)` / `setShadow(false)` 生效时无残留 hachure。
- 关内第二次进入画面与第一次**逐像素一致**（确定性随机）。

## 八、实施顺序建议（按"感知收益 / 风险"排序）

| 序 | 内容 | 理由 | 风险 | 预期感知 |
|---|---|---|---|---|
| **1** | 色板落地 + `paperLayer` 烘焙 + 土体剖面纹理(2.3) | 全屏最大的灰块变厚；顺带省每帧路径，是"降风险"而非"加风险" | 低（纯静态、纯绘制） | ★★★★★ |
| **2** | 天空渐变/远山三层/云带/近云 + 地平线晕染 + 暗角颗粒(3.1/3.2/3.6) | 上半屏从"灰板"变"清晨田野" | 低 | ★★★★ |

## 九、命名与交付约定（给主程序）

- **代码归属**：新增布景统一 `src/render/scenery.js` → 导出 `drawLevelScenery(ctx, level)`（在 `drawStatics` 内调用，静态）与 `drawAmbient(ctx, state, t)`（在 `drawBodies` 之后、`drawBook` 之前调用，动态，裁剪到 `0..BOOK_TOP`）。
- **scenery kind 命名**（若沿用 `level.scenery` 数据驱动）：`glow` / `hills3` / `cloudband` / `cloudline` / `tufts` / `haystack` / `rimstones` / `pennant` / `stall` / `stakes` / `canopyfold` / `water` / `reeds` / `ripple` / `rust` / `cracks` / `wind` / `grain`。
- **绘制函数命名**：`drawSc_[元素]`（静态）、`drawAm_[元素]`（动态），例如 `drawSc_Tufts`、`drawAm_Wind`。
- **图层裁剪**：`drawAmbient` 首行 `ctx.save(); ctx.beginPath(); ctx.rect(0,0,DESIGN_W,BOOK_TOP); ctx.clip();`，结尾 `restore()`——**动效永不越界到造物簿**。
- **色值**：一律引用第二节令牌；**禁止在代码里出现表外 hex**（评审 grep 兜底）。
- **确定性**：所有随机（石/草/颗粒布局）用 `nextInkSeed()`，同关卡布局固定。
- **文件命名**：本规格 `art-polish-spec.md`；后续如出增补，走 `art-polish-spec-vX.md` 并在本文标注取代关系。

### 红线清单（违反即打回）
1. 不改 `level.terrain / props / plates / goal / spawnY / guides` 任何数值；不改 `chipRect()` / `headerButtonAt()` 命中区。
2. 不改物理参数、不改判定、不改关卡几何。
3. 农夫不得填色卡通化；布景不得用彩色线。
4. 动态层禁用 rough；动效不得越界进造物簿。
5. 低于 mid 档不得残留 hachure / 阴影。

## 一、关 4 · 上不去的高台（难度 3 · 认知变量：配对）

### 1.1 一句困境
> 小人要上比自己高约四倍（≈130px）的平台，平台边有块薄石台（可踩），他自己跳不上，也没有梯子。
> 开场台词（小人）：「上面有我要的东西。我够不着。」（14 字，`l4_intro`）

### 1.2 本关露出芯片（4 个，符合 R2 关 4=4）
`变硬 (harden)` · `变重 (heavy)` · `怕痒 (tickle，新增)` · `变轻 (light，对照组)`

### 1.3 几何数值表（坐标齐全，直接照抄进 `src/level/levels/ch1-04.js`）

坐标约定与 `ch1-01..03` 一致：地形 `{x,y,w,h}` 为**中心 + 宽高**；y 轴向下；设计宽 `DESIGN_W = 430`。

| 构件 | 几何（中心 x,y / w,h） | 顶面 y | 说明 |
|---|---|---|---|
| 低地（小人出发） | `{x:120, y:471, w:240, h:82}` | 430 | x 0..240，与高台在 x=240 处**直接相接**（无坑，防小人走下去） |
| 高台 | `{x:330, y:370, w:180, h:140}` | 300 | x 240..420，顶面 y=300；比低地高 130px ≈ 4.6× 小人高度 ⇒ 「高四倍」 |

> **坐标系参照物（D22）**：高台顶面 `y=300` 是「上去了」的判定基准；小人落地中心 y ≈ 286（半径 ≈14）。`maxY:320` = 平台顶 + 20px 容差，落点在台上即 y≤320；低地 y=416 远超 320 ⇒ 不会误判。低地右缘 x=240 与高台左壁 x=240 相接 ⇒ 小人走到 x≈234 被墙挡住、原地跳（跳不上去）、不坠坑。

### 1.4 芯片清单与「配对」教学
- **怕痒（tickle，新增，~30 行钩子）**：被任何刚体接触时，沿接触法线**反方向**施加一次冲量 `J = k × mass`（⇒ Δv = J/mass = k 恒定，与画多大无关，纯 D15）。实现为 `registry.js` 的一条 `hooks.onContact`：取 `contact.normal`，`Body.applyForce/setVelocity` 沿 `-normal × (k × mass)`；**冷却 200ms** 防一次接触多帧连发；`kind==='creature'` 自身不对自己触发；不计「咬合/破坏」，只反弹。约 30 行。
- **变轻（light，对照组）**：已实现。单独用 = 乱飘；与怕痒相乘 = **no-op**（D15：J 与 m 同比缩放、Δv 不变）→ 这是本关要教的「配对要贴对，不是贴得多」。

### 1.5 解法 ①②③（≥2 真解 + 团块兜底，全部可过）

**① 长条 → 变硬 + 怕痒 = 不变形弹射板（配对主解，必稳定可学）**
- 做法：在低地 x≈180..250 画长条 → 点「变硬」「怕痒」→ 落在小人脚下（他正卡在 x≈234 墙根，板就在他脚边）。小人踩上 → 怕痒 沿接触法线（向上）触发冲量，Δv 恒定 ⇒ 小人被弹起；他此时正朝 targetX(340) 有向右速度，抛物线落上高台（x 240..420, y≤300）。
- 为什么可学：怕痒 Δv 恒定（D15），**画粗画细弹一样高**，不抽奖。
- **引擎支持确认（读 `runtime.js` 结论）**：walker 是 matter 圆体；`stepWalker` 只在 `standing`（地面且 `|vy|∈(-1.2,1.0)`）时覆写速度。**一旦被弹离地，vy 超出窗口 ⇒ 该帧起 `stepWalker` 直接 return，不再覆写速度** ⇒ 小人可被造物冲量带着飞。模型上支持「把小人弹起来」，**不许把"引擎不支持"写进规格**。
- **标定兜底（设计侧，非引擎借口）**：若实机 `tests/l4-launch.mjs` 显示 10 次中 <8 次上平台，则降级几何——平台降到「高三倍」（顶面 y=330）或低地右侧加一块 `变硬` 团块垫脚（顶面 y=365）让弹射只需补上半段；两种都是**改几何不牵涉引擎**。

**② 三笔短条 → 松散堆 → 变硬 = 三块硬台阶（兜底真解）**
- 画三笔不相连短条 → 判松散堆（`pile`）→ 逐块点「变硬」→ 三块硬块叠成台阶（x 200/220/240，逐块升高 40px）→ 小人一级级走上去。踩歪会滑，多试两次即可（D7 同口径：变硬=可承载，撑不住算实现缺陷）。

**③ 长条 → 变硬 = 斜靠斜坡（老手解）**
- 长条斜靠在平台左壁（下端在低地、上端搭到薄石台 y=292）→ 变硬 → 小人沿斜面走上去。需精准角度。

**④ 团块兜底**：团块 + 变硬 也能堆出踏脚石（兜底形态，appendix A 铁律），保证画得丑也过得去。

**变轻对照组（实验型对照，D20）**：第 1 次贴「变轻」**不点明**（毫无变化本身就是信息）；同一方向重复第 2 次仍无进展 → 小人说「变轻它只会飘，不会弹。」（11 字，纯文字、不朗读，`l4_control_light`）。只解释变轻管什么，不说「你贴错了」。

### 1.6 判定与目标类型
- **目标类型**：`reachActor`（关 1/2 同款，运行时已支持，见 `runtime.js` `checkGoal`：`a.body.x >= g.x && a.body.y <= g.maxY`）。**无需新目标类型**。
- **失败反馈（不死路）**：无致命失败；若被弹飞坠出 `resetActorIfBelowY:620` → 小人回起点、`fail('actor-fell')`、造物不销毁、可重试。
- **鼹鼠评论员（关 4 首登场）**：小人摔进草丛/坠地时（失败终态）说一句吐槽（纯文字，不朗读）。原 §9.2「隐藏解法触发（关4）鼹鼠『这不是桥。这是犯罪。』」因关 4 已无隐藏解，**触发条件改为失败吐槽**，台词文本沿用。

### 2.4 芯片清单与「作用对象转向」表达
关 1–4 你造的东西都是**帮自己**（更好的桥/跳板）。关 5 必须**作用于第三方**——鱼（敌方）或河（环境）：
- **怕痒** → 作用于**鱼**：造物被鱼撞 → 弹开鱼（见解①）。
- **变重** → 作用于**河**：把河填出一块踏脚石，改的是环境（见解②）。
- 变硬/会滚/变轻 → 辅助（桥、垫、浮力），但**单独造桥不算本关认知变量**，故不作主解。

### 2.5 解法 ①②③（≥2 真解 + 团块兜底）

**① 变硬 + 怕痒 = 挡鱼弹板（作用对象=敌方鱼，主解）**
- 做法：在鱼巡游线（x 160..270, y≈350）上方架一块 `变硬+怕痒` 造物。鱼游来撞到它 → 怕痒 触发：造物被弹开，鱼被碰撞副产物（牛顿第三定律 + matter 法向解算）弹回己侧（x<160）→ 露出空隙，小人趁机过桥。
- 若实测鱼弹不回（调参问题），降级为「怕痒 挡板横在鱼线」：鱼撞板→板弹起→把鱼挤到一侧，留半幅空隙给小人过。**改的是布置，不是引擎**。

**② 变重 + 变硬 = 填河踏脚石（作用对象=环境，主解）**
- 做法：画团块/长条 → 点「变重」「变硬」→ 丢进河里 x∈[150,280] → 沉底形成踏脚石（顶面≈350）→ 小人从河面踏石过去，避开鱼的主泳道（鱼在 y≈350 但踏石顶面可踩、鱼被挤到两侧）。这是「我改了河，不是造了更好的桥」。

**③ 长条 → 变硬 = 跨河长桥（老手解）**
- 变硬长桥一次跨 150..280，小人走过；需配合时机避开鱼（鱼撞到桥上小人→被顶回，见失败反馈）。

**④ 团块兜底**：团块 + 变硬 也能堆出河中踏脚石（兜底形态）。

### 2.6 判定与目标类型
- **目标类型**：`reachActor`（同关 4，已支持）。
- **鱼的行为（动态 prop，非机关）**：鱼是 `kind:'fish'` 的 prop，水平巡游（runtime 新增 `updateFish`：x 在 [xMin,xMax] 间按 vx0 往返，遇界反弹；不与地形卡死）。**鱼碰小人 → 重置小人回起点**（`fail('actor-bitten')`，不死亡、不销毁造物、不销毁鱼）→ 失败可推进，符合 D23/D25「失败必须是能推进的失败」。
  - ⚠️ **不是咬合机关**：鱼只做「碰撞 → 顶回小人」这一件事（纯物理接触 + 重置），不固定/不破坏/不移除任何物体。属 prop 行为，关 2 南瓜同族先例，不新增机关原型。
  - **儿童安全**：鱼「顶」不「咬」，小人被顶回岸边说吐槽、浮在水面，绝不表现伤害（对齐 §关5「鱼不咬人，只咬桥」原设定的安全基调，改为「鱼不咬人，只顶桥上的人」）。

## 三、沙盒模式 · 造物园（通关 5 关后解锁）

### 3.1 定位
全通关 5 关后解锁的「造物园」，承接「主角可以造出天地万物」的核心承诺（D1：沙盒作为通关奖励）。无过关判定、无失败、无计时。

### 3.2 入口
- **主解锁点**：第 5 关 `win` → 播放通关印章（`stamp5`，文本「第五章：你已能造物。」）→ 标记 `progress.allCleared = true` → 标题页出现「造物园」按钮。
- **直接进入**：标题页检测 `SaveStore` 中 `wcwz:progress.allCleared === true` 即显示入口，不强制走盖章演出。

### 3.3 进场 / 退场
- **进场**：自由绘制画布（无 `goal`、无 `chips` 上限之外的限制），全部已解锁能力可贴（每造物 ≤2，沿用全局 `MAX_ABILITIES_PER_CREATURE`）。
- **退场**：返回标题页；造物自动存入 `SaveStore`（见 3.4），不丢。

### 3.4 持久化字段（沿用 `SaveStore` 抽象，新增一个 key）
- key：`wcwz:sandbox:v1`
- value：
  ```json
  {
    "unlocked": true,
    "creatures": [
      { "id":"c1", "form":"beam", "strokes":[...], "thickness":12,
        "abilities":["harden","tickle"], "name":"桥", "x":200, "y":300, "createdAt":1700000000 }
    ]
  }
  ```
- 上限 **30 个**；超出提示「先删掉旧的」（不静默丢）。
- 迁移：`SaveStore.migrate` 已有 v1→v2 先例，新增 key 走同一套。

### 3.5 幽默反馈（沙盒吐槽）
- 造物落地 / 互动时随机吐槽，**来源限于既有闭集风格**（附录 A 形态台词 `form_*` 可复用；新增 `sb_toss1..4` 纯文字、不朗读、风格对齐「角色只自嘲、不评价玩家」）。
- 禁用话术黑名单（与 `core.test` 闭集断言同套）对沙盒吐槽同样生效。
- 例（`sb_toss*`）：「你又造了个我。我谢谢你。」「这玩意儿比上次的还圆。」等，均 ≤18 字、纯文字。

### 3.6 机器可验验收标准

| 判据 | 门槛 | 测试 |
|---|---|---|
| 解锁门禁 | `allCleared=false` 时标题页无入口；`=true` 时有 | `tests/sandbox-unlock.mjs` |
| 持久化 | 存 5 个造物 → 刷新页面 → 仍在、字段一致 | `tests/sandbox-persist.mjs` |
| 无 goal 不误判 | 沙盒场景 `goal=null` → 永不 `win`、永不 `fail` | `tests/sandbox-nogoal.mjs` |
| 能力可贴 | 全部已解锁能力可点、每造物≤2 | `tests/sandbox-chips.mjs` |
| 吐槽闭集 | 所有 `sb_toss*` 在 `lines.js` 存在且 ≤18 字、不进语音 | `tests/sandbox-lines.mjs`（复用 core.test 闭集断言） |

### 4.4 范围红线（主程序勿越）
- 关 4 / 关 5 **不新增任何机关原型**（不写咬合/感光/沙漏逻辑）。
- 鱼的「顶人」只允许「碰撞 → 重置小人」，禁止「固定/破坏/移除」物体。
- 怕痒 `Δv` 必须恒定（D15：`J=k×mass`），**不得改回固定 J**（否则画大的孩子过不了关，已实证）。
- 变轻 + 怕痒 的 no-op 必须保留（对照组，D15），不得为「让它有点用」去增强弹射。

## 五、关 5 换案的最终决定（回传结论）

**保留「河 + 鱼」视觉主题，因咬合机关被禁，将「鱼咬断桥」改为「鱼游进桥道把小人顶回岸边」（纯碰撞、无咬合、无伤害，符合「鱼不咬人」儿童安全）。认知变量「作用对象转向环境/敌方」由「怕痒 作用于鱼（敌方）」+「变重 填河（环境）」两条真解承载。关 5 芯片行由原文的〔变硬/会说话/透明/滑/黏〕替换为已实装的〔变硬/会滚/变重/变轻/怕痒〕（5 个，符合 R2 关 5=5）。§9.2 关 5 两条台词因「咬」字不再适用已改写为「顶」。** 此方案在「不新增机关类型」「只用已实装能力 + 怕痒」「鱼为可见 actor」三条硬约束下完全可施工，无需引入任何第 5 类机关。

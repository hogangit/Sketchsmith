## 关5《河里有条鱼》重做 —— 根治「画一条横杠就能过」（D34）

用户反馈：第5关太简单、画一条横杠就过、跟第1关雷同；湖里的鱼是橙色长方形不像鱼；关卡跟鱼没关系。

### 根因（物理层，非调参）
造物从顶部 `y=84` 生成、自由落体 → 形状决定形态、落点永远从顶掉下。
「画一条平梁」掉下来会自动歪成坡搭在两岸之间 → 本质仍是「一条梁过」。
实测三代（礁石18px / 高岸50px / 68px 高墙双坡）全部被下落物理压成可走的桥。
⇒ 桥类关必然「一条梁过」，靠「河更宽/墙更高」救不了。

### 解法：弹射越过鱼潭（用户痛点根治）
- 关键几何事实（实测标定）：梁是**水平**掉下（无水平初速、质心对齐 spawn.x）；一旦歪斜，右端水平投影**只会往左缩**（绕左岸沿旋转，cosθ<1）。
- ⇒ 对岸左缘放到 **x378**（> 梁右端 x360+pad≈366），单梁永远撂不上去，只能坠河。
- 左岸 x0..242 顶 y300；鱼潭 x242..378（136px）；对岸高墙 x378..430 顶 y170（高130px）。
- 主解：左岸画「变硬+怕痒」弹射板（中心≈190），小人被弹起、抛物线从鱼潭上方掠过、越过墙顶角落到对岸。
- 鱼=落水威胁（掉河被顶回，`actor-bitten`）；真鱼绘制 `drawFish`（椭圆身+摆尾+鳍+眼+嘴）已修「长方形」缺陷。

### 标定与验证
- `tools/probe-l5.mjs`（node 真物理探针，新增）：弹射窗口 `cx∈[160,230]` 全过；`cx≤150` 落点偏低撞对岸左壁。
- 冒烟：`L5 弹射板`（line `[165,700,215,704]`, harden+tickle）→ 过关 2.0s；`L5 单根长板`（`[150,700,360,704]`, harden, expectFail）→ 正确失败 ✔。
- 全量回归：core 20/20、L2 0 未达标、L4 10/10、沙盒 7/7、perf 6/6、完整冒烟「全部通过」。
- 已知边界：库内无梁长上限，玩家故意画 >228px 超长梁（右端过 x378）仍可能搭桥；属引擎级限制，本关不修，目标是根治「随手一条横杠就过」的默认痛点。

## 追加②（同日）：第4关「画很多形状都会变成圆形」——形态识别两处修复（D36）

**用户反馈**：「第4关画很多形状都会变成圆形，检查一下是不是有问题」→ 查了，是真问题，两条。

### 缺陷① 闭合 + 长宽比≤1.5 ⇒ 一律替换成完美圆
- 判定树序5 只看长宽比（`classify.js`）→ `body-factory` 对 wheel 用 `Bodies.circle` ⇒ 方块/三角/星形全变成会滚的圆柱。
- 真浏览器实测（dist/game.html + poly-decomp，`tools/probe-form-browser.mjs`）：
  正方→圆 r=25、三角→圆 r=24、星形→圆 r=32.3；圆/椭圆本该如此（wheel 保留）。
- 修法：轮补两条圆度判据 **circularity=4πA/P² ≥0.86** 且 **solidity=A/hullArea ≥0.86**，
  不够圆就落 blob（走真实多边形）。标定：圆系 0.95–1.03、六边形 0.93、五边形 0.88 ‖ 方块 0.80、三角 0.62、星形 0.02。
  阈值写进 `src/stroke/thresholds.js`（红线：不许散落到 classify）。

### 缺陷② 精确闭合的笔画直接「什么都不生成」（查①时连带发现）
- `rdpCore` 用「点到首尾连线的垂距」分治；玩家把圆/方**认真画回起点**时首尾重合 → 连线长≈0 →
  所有点垂距退化成同一常数 → maxD≤ε → 整条笔压成 2 点 → 周长 0 → `tooSmall` → toast「太小了」、刚体不生成。
- 现有 test helper（`synthRect/synthCircle`）都刻意留 gapPx 缺口，**bug 从未被测试碰到**。
- 修法：`len < ε` 判为退化，改以「离首点最远的点」切环成两段有真实弦的子路径再递归。精确闭合的圆简化后 ≥6 点。

开口笔画没有面积，只能拿外包（K3 退化链）顶：斜线→bbox 矩形、L/V 形→3 顶点三角形、涂鸦→hull 11 顶点。

# 2026-10-26

## 《我是造物主》项目启动（1024 造物挑战，截止 2026-11-01）

- 交付形态定为**单页 Web 游戏**，无后端/无账号/无网络依赖；可用工期约 6 天。
- 建立 `docs/decisions.md` 作为唯一决策来源；git 已初始化，前两次提交 `71716de`、`97043f8`。
- **D1**：主循环 = 关卡剧本制为主，沙盒作为全通奖励；不做剧情编辑器，自由度载体是「每关 1 个自由造物槽」（玩家造什么，剧情就演什么）。
- **D2（暂定，用户未明确点选）**：造物实体化 = 「形状即物理」A 方案。系统**不做语义识别**，只提取笔画几何属性（长度/闭合/面积/重心/笔画数）映射为梁/轮/团块/容器/绳；能力改变行为规则而非形状；**名字只影响外观与台词**。文字输入走「修饰词+名词」关键词组合，不接大模型。
  - 差异化依据：Doodle God（元素合成）、Scribblenauts（打字召唤）、Draw a Stickman（画的变预设道具）的共同点是「系统已知那是什么」，本作反之。
- **关卡设计案 v1**（游有方）落盘 `docs/levels.md`：3 章 / 9 关 / 24 能力 / 形状→形态映射表 / 三级提示阶梯 / 首关 30 秒开箱设计。
  - 难度曲线的可执行定义：**每关只新增 1 个认知变量**（关1 零变量 → 关9 九变量）。
  - 设计铁律：任何关卡的必需解法都要存在「团块（兜底形态）+ 某能力」的路径，保证画得丑不会走进死路。
- 制作人核查出 3 项待修订（R1 关7 时间慢 vs 沙漏矛盾／R2 能力芯片解锁节奏不一致／R3 9 关≈9 套机关工期风险），按「口径变更攒成一张变更单」处理，待用户确认后一次性下发给游有方。
- **竞品扫描**（`docs/research.md`）：真正拥挤的是"画线即固体"品类（Crayon Physics / Brain It On! / Happy Glass / Bro draw it / Draw Logic Puzzle / 画 Sprunki 小车），共同机制只有"画→静态刚体"。定位句 D6：**别人让你画"挡板"，我们让你画"物理法则"**。开源复用：matter-js 0.20.0 + poly-decomp 0.3.0 + roughjs 4.6.6 + perfect-freehand 1.2.3（全 MIT），内联约 105KB；不用 Tone.js / howler / planck.js。
- **D4 音频**（`docs/audio-spec-v1.md`）：零素材三层。BGM 五声音阶实时生成（无 loop 点，动机变形+洗牌袋反腻）；SFX 噪声+滤波器包络；语音 speechSynthesis 只用于情绪高点，**每局硬上限 16 条 / 40 秒**，绘制期间绝对静默，无 zh-* 语音时降级"文字气泡"模式（不用英文声音念中文）。
- **技术基线**（`docs/tech-baseline-v1.md`）：Canvas 2D + matter-js；构建 `node tools/build.mjs`（esbuild 单二进制，必要时退化为纯字符串拼接）；单文件体积硬门禁 600KB；P0 机型 = 骁龙 665/720G + iPhone 8，DPR cap 2；形状判定 S1–S12 三级退化链（decomp→凸包→bbox→圆），自交不做交点修复；24 能力写成纯数据记录（mods/hooks/flags/layer/priority），禁止 24 个 if-else。
- **关卡案 v2**：变更单 R1–R4 全部落地——沙漏不受"时间慢"影响、芯片随关卡解锁（1→6 封顶）、机关收成 4 类原型（压板/感光/咬合/沙漏）、台词双层（大字长版不朗读 + ≤18 字短版走语音）。前 3 关只出 3 个能力（变硬/会滚/变重），变轻移到关 4 作为"看着没用"的教学。
- **D5 美术**：暂定手绘纸感（单色墨线 + 纸张纹理 + 仅能力生效时上色），用户未点选，按推荐采纳。
